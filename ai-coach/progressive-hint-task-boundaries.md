# Progressive Hint Task Boundaries

Math names a concept, then an operation, then an unsimplified setup. Proof identifies a theorem, inference, then partial frame. Multiple choice provides criteria without a decisive option. Writing leaves student-authored content. Coding uses incomplete pseudocode in another domain. Research uses source actions and claim-evidence structure. Labs leave analysis/conclusion. Reflection never writes first-person experience. Translation preserves student completion. Every subject retains the Step 30 answer boundary.
