# Climate Prompt Iteration Example

Version 1: “Explain climate change.”

Version 2: “Explain the greenhouse effect to a Grade 8 student using one analogy.”

Version 3: “Explain the greenhouse effect to a Grade 8 student using one analogy, identify the analogy’s limitation, and provide two reliable sources.”

Version 2 narrows the topic and adds audience/format. Version 3 adds the analogy limitation and sources. Controlled synthetic outputs show that Version 2 may suit quick review while Version 3 may suit evidence-aware learning after sources are opened. Longer is not automatically better, and clarity alone cannot establish factual reliability.
