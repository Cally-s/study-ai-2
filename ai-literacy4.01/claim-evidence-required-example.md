# Required Attendance Example

Claim: “The program increased student attendance.”

Evidence: “Attendance rose from 82% to 88% during the pilot.”

Source: “School pilot report.”

Reason: “The report contains before-and-after attendance data.”

Limitation: “The pilot lasted only eight weeks and did not include a comparison group.”

The evidence supports the measured change, not that the program alone caused it. Revised: “Attendance increased from 82% to 88% during the eight-week pilot. Because the report did not include a comparison group, it does not establish that the program alone caused the increase.”
