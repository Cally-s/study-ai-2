# Accessibility

Review keyboard, screen reader, focus, headings, 200% zoom, 320 CSS pixels, contrast, reduced motion, speech, captions, transcripts, plain language, reading level, bilingual, RTL, low-bandwidth, text, print, audio, and error recovery. Avoid colour-only and drag-only interaction.

## System-card disclosure

Each accessibility feature is separately marked planned, implemented, or tested and linked to evidence; intention or automation does not certify accessibility.

## Accessibility fairness

Compare essential information, source/uncertainty, task completion, correction and reviewer access across input/output, device, language, bandwidth, keyboard, screen-reader, speech, audio and transcript paths.
