# Recovery Notification Copy Standard

Good: “Your 20-minute Mathematics review is scheduled for 6:30 p.m.” “The English assignment is still waiting for a teacher decision. No action is required tonight.” “You have 30 minutes available today. Would you like to protect the Chemistry outline or review for Mathematics?”

Never use guilt, failure, overdue counts, streaks, peer/sibling comparison, grade threats, blame, urgent commands, repeated punctuation, or unsupported dates/availability/decisions/completion/booking. Use exact dates/times, one confirmed fact, one action or two-option choice, preserved uncertainty, and explicit No action required wording.
