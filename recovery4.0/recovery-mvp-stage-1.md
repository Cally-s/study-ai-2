# Recovery MVP Stage 1 — Intake

The complete independent journey is Help Me Catch Up → mode selector → manual task entry/edit/remove → realistic date-specific available time → neutral inventory → private Save, Save and Pause or exit. Status Unknown is supported; Submitted, Completed, Blocked and Waiting remain distinct. No Longer Required needs authority.

The inventory groups upcoming, unresolved, submitted, blocked, waiting and unknown work plus capacity. It shows no plan, raw score, prediction, streak or ranking when Stage 2 is disabled. Existing Recovery entry, work and capacity services implement this prototype journey. Cross-device persistence and manual keyboard/screen-reader acceptance remain unverified.
