# Strengths-Based Parent Summary Language

Approved wording is accurate, neutral, and action oriented: “The student created a realistic seven-day plan,” “Four assignments require teacher decisions,” and “The student asked for specific practical support.”

The deterministic validator blocks negative character, motivation, effort, and shaming language; unsupported progress/negative claims; and ungrounded overstatement. Terms such as lazy, irresponsible, unmotivated, not trying, poor attitude, and bad student cannot enter an approved summary. Progress is never exaggerated, and stopping at the protected time or asking for help may count only when the source record supports it.
