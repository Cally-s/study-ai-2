# Recovery Plan Saving

Save modes are Do Not Save, Encrypted Device Only, Private Account Storage, School-Managed Required Storage, and Unavailable. The broadest retention is never preselected.

Do Not Save uses disclosed temporary processing, creates no cloud plan or persistent search index, warns before closing, and offers export. Device Only does not sync, warns on shared devices, expires, and supports local deletion/logout cleanup. Private Account Storage syncs securely but creates no share. Required Storage is shown before entry where possible and suppresses impossible controls. Autosave preserves versions but never creates external access.
