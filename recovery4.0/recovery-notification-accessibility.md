# Notification Accessibility

Settings use semantic fieldsets, labels, native controls, visible focus, 44px targets, polite non-repeating status messages, keyboard operation, 320px/200% reflow, forced colours, Reduced Motion, Text-to-Speech, Language Bridge, RTL, simple language, dyslexia/reading-ruler modes, and Low-Bandwidth text-first output. Sound, vibration, autoplay, flashing, and pulsing default off. Manual browser and assistive-technology results remain NOT RUN.
