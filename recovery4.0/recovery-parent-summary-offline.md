# Parent Summary Offline Behavior

Cached section/fact selection, support requests, draft editing, privacy review, Copy, cached Print View, Save and Pause, and cached version review may work offline. Recipient account confirmation, secure links, email/in-platform sharing, new source retrieval, and new teacher/deadline confirmation do not.

An offline share is never queued. Reconnection displays that the summary is ready, reloads freshness and recipient state, and requires approval again after material changes plus a new explicit sharing action.
