# Parent Summary Approval

Every included section must be reviewed and approved. The student then reviews Included and Not Included information, completes the privacy review, reviews exactly one recipient, previews the complete summary, and intentionally approves the snapshot.

Final approval requires current sources, no hard-excluded content, valid strengths-based language, and all included sections approved. Material source changes show the affected section, old value, and new value, invalidate approval, and preserve student edits. Sharing always requires a subsequent explicit action.
