# Plan Recalculation Offline

Cached requirement/estimate/reason/smaller-action/capacity context and provisional revisions may save offline. No teacher decision is fabricated; no message, tutor booking, parent update, plan activation, reminder, or rollover is queued.

Reconnection revalidates plan, work, requirement, deadline, prerequisite, and capacity versions. Material changes invalidate approval and require renewed preview. Idempotency prevents duplicates; unresolved conflicts preserve both proposal and current plan for review.
