# Prerequisite Help Accessibility

Source contracts provide semantic one-step sections, native controls, visible focus, text math, bounded hints, approach/count announcements, reflow, forced colours, reduced motion, RTL, simplified/dyslexia/reading-ruler, low-bandwidth and print modes. TTS needs accessible math speech; STT requires review. Browser/keyboard/screen-reader, 200%/320px, high contrast, Language Bridge/RTL and participant tests remain `NOT_RUN`; inaccessible attempts never count.
