# Recovery Calendar Capacity Review

Calendar review requires an approved revocable connection, minimum read-only/free-busy scopes, selected range and selected busy blocks. Titles are hidden by default and blank gaps are only possible availability—not confirmed study time. The student must separately confirm actual capacity.

This repository has no calendar connector or OAuth/free-busy service. Capabilities report unavailable, connection lists are empty and preview/import/refresh/revoke calls fail closed. Manual totals/windows/commitments remain available. No password, token, title or private event is collected or exposed.
