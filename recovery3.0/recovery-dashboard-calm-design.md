# Recovery Dashboard Calm Design

Ordinary states use neutral icons plus text: Ready, Information, Waiting, Needs Review, Due Soon, Resolved, and Paused. High-intensity styling is reserved for immediate safety, destructive confirmation, or critical system failure. Colour is never the only signal.

No wall of red overdue cards, flashing/pulsing/countdown, autoplay, animation, confetti, guilt, streak, rank, points, comparison, score, or unstable percentage is used. Stretch is secondary and Finish for Today remains visible.
