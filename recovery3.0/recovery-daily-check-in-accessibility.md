# Daily Check-In Accessibility

The source view uses one short question section at a time, semantic heading/fieldset/legend/labels, native radio/buttons, visible focus, and no drag/hover/mouse/audio requirement. It supports keyboard access, screen-reader labels, 200%/approximately 320px reflow, extra-large text, high contrast/forced colours, reduced motion, dyslexia display, reading ruler, RTL, text-only, and low bandwidth.

Listen never autoplays. Speech input requires permission and editable review. Language Bridge preserves outcome/action meaning. Browser, assistive-technology, speech, language, display, and representative-user results remain `NOT_RUN` until actually executed.
