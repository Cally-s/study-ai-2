# Recovery Action State Machine

Execution (Not Started/In Progress/Completed/Blocked/Waiting), Schedule (Unscheduled/Scheduled/Rescheduled/Removed/Superseded), Review and Validity are separate. The resolver displays No Longer Required, Blocked, Waiting, Completed, Rescheduled, In Progress, then Not Started. Completion needs student-work evidence; timers/dashboard opens cannot complete. Blocking, waiting, rescheduling, revision and reopening preserve progress/allocation history.
