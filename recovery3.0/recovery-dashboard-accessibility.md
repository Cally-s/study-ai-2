# Recovery Dashboard Accessibility

The dashboard uses a skip link, one primary heading, five ordered labelled sections, native buttons/details/links, polite status, visible focus, and text status labels. At 200% or about 320 CSS pixels all areas stack Today–Help–Week–Progress–Recalculate, bilingual content wraps/stacks, and ordinary horizontal scrolling is absent.

Contracts cover keyboard, screen reader, high contrast/forced colours, Reduced Motion, TTS without autoplay, bilingual/important English terms, RTL, Plain Language, Low-Bandwidth, print, and Overwhelmed SIMPLE density. Manual AT/browser verification remains NOT RUN.
