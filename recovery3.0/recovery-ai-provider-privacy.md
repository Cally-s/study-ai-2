# Recovery AI Provider Privacy

Only fields necessary for the selected function are sent, using opaque identifiers and excerpts/summaries instead of profiles, unrelated courses, sensitive personal data, full files, or full conversations. Policy/status meaning is preserved.

The Privacy Centre identifies provider/category, purpose, data classes, region when available, retention configuration, training setting, subprocessors, policy version, and contact. Model training/fine-tuning/broad improvement is off by default. Any future opt-in must be separate, default off, withdrawable, approved, and protected for minors; unavailable controls are not shown.
