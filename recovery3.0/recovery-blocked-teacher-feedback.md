# Blocked Teacher Feedback

Link an existing Step 22 thread or prepare one concise draft for feedback, permission, clarification, priority, deadline, acceptance, or meeting. Only confirmed Send creates Waiting for Teacher; Draft is not Sent, Sent is not Received, and Received is not Approved.

Set a review point and show another ready task. Follow-up is merely recommended after a confirmed send, reasonable school interval, continued dependency/risk, and no student decline. It remains reviewed and explicitly sent—never automatic or repeated daily.
