# Meaningful Badge Criteria

Students see all required criteria and acceptable evidence before applying. Packages map exact immutable evidence versions to each criterion and include at least one reasoning, explanation, verification, reflection, rationale, or documented decision. Authentic assessment, Independent Retry, Teach-Back, source, System Card, fairness, prototype, and community-project records are eligible when authorized. Counts, completion, speed, popularity, detectors, hidden requirements, and private/safety data are prohibited. Applied Independently requires valid Step 52 evidence. Humans review criteria separately; no hidden percentage or global score is used.
