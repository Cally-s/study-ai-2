# Competency Portfolio Structured Data

Schema `competency-portfolio/1.0` defines tenant-scoped versioned Portfolio, Section, Item, Competency Evidence Link, Share Configuration, immutable Share Snapshot, Shared Item Snapshot, Audience Grant, Community Feedback, Review, private Submission Snapshot, and Event records. Share state is separate from private portfolio state; selected item versions are explicit; sanitized snapshots contain no live private references.
