# User-Journey Final-Answer Tests

UJ-001–UJ-006 and UJ-047 verify server-enforced answer restrictions. The scanner requires and inspects visible response, structured data, sources, claims, tools, accessibility names, live regions, captions, transcripts, print, downloads, client state, API payload, stored references, logs, and analytics. A planted answer in any surface fails the scan.

The real structured-response validator is also exercised with a candidate that combines a final-answer leak, unsupported high confidence, and prompt injection; it rejects all three violations.
