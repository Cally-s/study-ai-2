# AI Literacy Lesson Structure

> Step 65 canonical mapping: versioned lesson definitions remain separate from `AILessonProgress` and immutable attempt rows. Attempt counts, completion, status, and assessment values are server derived; the progress record only owns resumable position and explicit state.

Every lesson version has an `AccessibleActivityContract` covering keyboard, screen reader, speech, captions/transcripts when media exists, contrast/motion, reading/language adaptations, canonical terminology, print/audio, accessible complex content, and alternative responses. Adaptations preserve canonical objectives, policies, sources, evidence criteria, uncertainty, answer boundaries, and student progress. Critical omissions block publication.
