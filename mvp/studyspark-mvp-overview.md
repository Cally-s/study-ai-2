# StudySpark MVP Overview

StudySpark uses six ordered vertical releases:

1. **MVP Stage 1: Coaching and Integrity Foundation**
2. **MVP Stage 2: Transparent Responses**
3. **MVP Stage 3: Apply-Level Tools**
4. **MVP Stage 4: Teacher Controls**
5. **MVP Stage 5: Create-Level Projects**
6. **MVP Stage 6: Full Accessibility and Offline Support**

Each stage depends on every earlier stage. Later work may exist in Internal Testing behind false server-controlled flags, but cannot be released or exposed in navigation until its own vertical-slice gate and all earlier gates pass. A vertical slice requires UI, server operation, authorization, persistence, validation, privacy, accessibility, error handling, tests, and documentation.

Authentication, tenant/role authorization, privacy before providers, final-answer boundaries, safe errors, keyboard/focus/semantic access, 200%/narrow layout, contrast, Reduced Motion, no automatic discipline, no prohibited scoring, minimized logging, and model-training-off are Stage 1 baselines. Stage 6 completes advanced language/access/offline coverage; it does not excuse inaccessible earlier stages.

Current truth: this repository is a client-side deterministic prototype. All stages remain **Internal Testing** and all public flags are false because no production backend, database migration, authentication service, build pipeline, or manual accessibility evidence exists.
## Step 70 measurement layer

Responsible AI Learning Success Measures add versioned, auditable evidence projections across the six MVP stages. They show separate verification, source literacy, independent transfer, explanation, prompt, disclosure, privacy, citation, fairness, and capstone indicators—never a global score or rank. Production dashboard release remains subject to the existing MVP gates.
