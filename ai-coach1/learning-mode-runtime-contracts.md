# Learning Mode Runtime Contracts

> Step 36 adds immutable quiz configuration, session, question, isolated answer-key/rubric, response, reasoning, evaluation, adaptation, reattempt, vocabulary, summary, and action records.

> Step 35 adds immutable answer versions, classified scope, materiality, validated bases, one challenge record, student responses, response reviews, final positions, and privacy-safe action events.

> Step 34 extends the existing contract with versioned student submissions, steps/dependencies, review/issue/verification records and revision links.

> Step 33 extends the existing contract with private session, skill/process, artifact, distance, transfer, and action records without replacing response metadata.

> Step 32 extends the Guiding Questions contract with session/turn/thinking/final-explanation state without replacing Step 30 metadata.

The server resolves safety, policy, assessment state, Academic Integrity, immutable mode snapshot, final-answer session, attempt, trusted task and answer boundary, tools, response parts, waiting, and validators before model invocation. Each contract has versioned allowed/prohibited parts, strict final-answer policy, tool permissions, one-action limit, schema, and fallback. Untrusted client, prompt, upload, webpage, retrieval, or model claims cannot define the mode.
