# Progressive Hint Prerequisites

> Guiding sessions link to the existing repair record, use one diagnostic question at a time, and resume the original context after the smallest prerequisite.

“Explain the prerequisite” links to the existing Prerequisite Repair/mini-lesson system and never increments the hint level. It identifies the smallest task-specific gap, uses one to three checks where needed, gives a plain explanation, a different example, one guided check, and a return prompt. It never solves the original. After repeated ineffective explanations, recommend human support without diagnosis or permanent label.
