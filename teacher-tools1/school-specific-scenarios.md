# School-Specific Scenarios

Scenario drafts may be fictional, synthetic, composite, or properly deidentified. Real student cases and unnecessary personal data are prohibited. Teachers review local terminology, accessibility, cultural context, and policy alignment before publication. The scenario links to the existing scenario system instead of creating a second catalog.

## Step 57 use
Scenario assessment validation adds target competencies, progression, primary task, reasoning requirement, response format, explicit criteria, valid alternatives, language equivalence, accessibility, and protected answer references before a published version can be assigned.
