# Offline Package Versioning

Published versions are immutable and retain package/code/source/manifest versions, stable question IDs, file size and digest metadata. Source changes require a new version and never silently replace downloads. Answers remain tied to original package/question versions; mismatch preserves old work for review/manual mapping/personal copy. The current FNV digest is prototype-only, not cryptographic integrity.
Step 18 components retain the exact source-plan version. Updated plans mark old artifacts outdated without replacing or changing historical content.
