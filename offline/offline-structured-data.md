# Offline Structured Data

> Step 65 canonical mapping: offline source and claim records retain `VERIFICATION_PENDING_INTERNET_ACCESS`. They remain excluded from competency projections until online verification and authorized review; synchronization never silently marks completion or overwrites an immutable version.

Schema `low-bandwidth-offline/1.0` defines mode, eligibility, activity/package/download/source/cache/sync/conflict/policy/event/violation/compliance states. Versioned records include policy, offline activity contracts, illustration assets, signed manifests/installations, local progress, source drafts/cached snapshots, synchronization batches/operations/conflicts, and content-free events. Formal completion, verification, evidence, recognition, badge, grade, public share, consent, and server acknowledgement are server controlled. Unknown/protected fields are rejected.
