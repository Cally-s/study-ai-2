# AI Coach Offline and Low-Bandwidth Behavior

Low-Bandwidth Mode renders the same validated card text first and does not weaken policy, evidence, privacy, source, language, or accessibility rules. When offline, the cloud coach displays **AI Coach unavailable offline.** Downloaded lessons, worksheets, transcripts, exercises, and drafts remain usable.

An offline prompt is never sent automatically on reconnection. The student reviews it, current policy/safeguards reload, privacy runs again, and a new run starts after confirmation. Cached source work remains **Verification pending internet access**.
