# Core Rule: Citation Metadata

`UNCONFIRMED_SOURCE_METADATA_NO_CITATION` permits citation only after source existence and identity plus title, author/organization, publisher, source type, retrieval location, and access date are confirmed. Publication/effective date and other format fields are included when applicable.

Missing values are never guessed. Search snippets and plausible-looking strings are rejected. Uploaded files are cited as supplied material only with confirmed available metadata and are not described as independently verified. Ambiguous identity/currentness/support remains uncited and may require human review.
