# AI Coach Student Attempt Gate

> Step 67 integration: graded-task detailed help is removed until a meaningful owned artifact exists. Typed, bilingual, diagram, equation, code, source-judgement, design, and reviewed-STT formats are accepted without word-count, speed, typing-style, behavior, or AI-writing scoring.

Attempt requirements come from policy, contribution checkpoints, mode, context, safeguards, assessment and retry rules, and teacher configuration. Valid formats include text, equations, diagrams, code fragments, spoken transcripts, and structured forms. Accessibility-supported and bilingual input remains valid.

The immutable gate stores artifact/version/provenance references, not raw work. Ownership is checked and only the server can validate status. It uses no word-count threshold, response-time heuristic, typing analysis, or AI-writing detector. Missing or ambiguous attempts restrict assistance and offer a first step, similar example, instruction help, or attempt entry; they never create discipline.
