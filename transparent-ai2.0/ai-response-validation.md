# AI Response Validation

Validation covers parsing/version, strict structure, unknown/required/enum/size rules, ownership, context/policy, mode/content, answer withholding, sources, confidence, assumptions, verification, question, disclosure, warnings, privacy, accessibility, cross-field invariants, safety, and immutable creation. Any failure prevents display. Safe errors contain no prompts, secrets, source text, hidden reasoning, or classifier scores. Production may regenerate once; repeat failure uses the deterministic structured fallback.
