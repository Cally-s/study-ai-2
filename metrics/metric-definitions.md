# Metric Definitions

Each published definition version records display purpose, category, role, unit, exact numerator and denominator, eligibility, exclusions, evidence, human review, source types and versions, calculation window, offline/late/missing-data policies, minimum denominator, suppression, dimensions, explanations, limitations, metric version, and calculation-code version.

The identifiers are factual verification completion; claim classification accuracy; independent retry success; explanation completion and quality; contextual hint/guiding selection; prompt improvement quality; required disclosure completion; safe privacy resolution; unsupported citation prevention; fairness quality; capstone feedback quality; and capstone revision rate. Percentage definitions without denominators are invalid.
