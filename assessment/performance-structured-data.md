# Performance Assessment Structured Data

Schema `performance-assessment/1.0` defines versioned tenant-scoped PerformanceAssessmentDefinition, PerformanceAssessmentAssignment, StudentPerformanceAssessmentWorkspace, PerformanceEvidenceArtifact, PerformanceEvidencePortfolio, RubricDefinition, CriterionEvaluation, PerformanceAssessmentTeacherReview, FeedbackResponse, RecognitionRule, PerformanceAssessmentRecognitionRecord, and PerformanceAssessmentEvent records. Submission freezes portfolio/artifacts; correction and revision create successors. Events retain safe identifiers/actions only.
