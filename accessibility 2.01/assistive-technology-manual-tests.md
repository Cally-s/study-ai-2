# Assistive-Technology Manual Tests

Planned combinations: NVDA/Firefox and Chrome on Windows; JAWS/Chrome and Edge on Windows; VoiceOver/Safari on macOS and iOS; TalkBack/Chrome on Android; Narrator/Edge; Dragon or OS voice input; ZoomText/OS magnification; and Switch Control where supported.

Scripts cover every major feature by keyboard, skip links, visible focus, logical reading/order/headings/landmarks, announcements, dialogs/focus return, math speech, captions/transcripts, media controls, form errors, zoom/reflow, language changes and recovery. Record exact announcements, assistance and issues. None of these tests has been performed; accessibility-tree inspection alone must not be reported as screen-reader testing.
