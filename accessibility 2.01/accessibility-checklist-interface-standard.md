# Accessibility Checklist Interface Standard

Checklist states are Pass, Needs Attention, Human Review Required, Unable to Test and Not Applicable. NOT_TESTED, UNABLE_TO_TEST and ERROR never map to Pass. Status uses visible text plus structure/icon—not colour alone. Native controls, logical headings, status announcements, keyboard operation, 200%/400% zoom, 320-pixel reflow, high contrast and forced colours are required. The persistent automated-check limitation notice remains visible.
