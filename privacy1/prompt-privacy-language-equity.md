# Prompt Privacy Language and Equity

The interface supports translated labels, bilingual content, RTL layout, non-Latin scripts, apostrophes, hyphens, mononyms, and unfamiliar names. Equivalent semantic findings receive equivalent handling across languages. A capitalized or unfamiliar name is never automatically high risk. Detector gaps fail to review, editing, or draft preservation—not punishment. Required equity fixtures include English, Mandarin, Arabic, bilingual prompts, public figures, cited authors, fictional examples, course codes, and academic names.
