# Prompt Privacy Secrets

Passwords, passcodes, security answers, API keys, authentication/session tokens, private keys, recovery codes, payment or bank details, government/passport/immigration identifiers, credential-bearing URLs, database passwords, and cloud credentials cannot enter the general AI Coach. Values are masked and must be removed. They are excluded from logs, analytics, crash reports, session replay, AI Use Receipts, and detector feedback. Legitimate examples use fictional placeholders. A StudySpark-controlled server recheck runs immediately before dispatch.
