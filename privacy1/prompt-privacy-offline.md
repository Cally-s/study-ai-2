# Prompt Privacy Offline and Low Bandwidth

Deterministic checks, review, editing, removal, replacement, and private draft preservation work locally. Offline mode cannot authorize or send and never creates a future-send queue. When connectivity returns, StudySpark resolves the current destination and policy, repeats the server secret scan, surfaces changed findings, and requires a fresh intentional confirmation. Account switching isolates drafts. The text-first experience does not depend on animations or large assets.
