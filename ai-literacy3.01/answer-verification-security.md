# Answer Verification Security

Original answers are immutable; claim spans and answer versions require validation. Source, answer, claim, uploaded, search, tool, and AI content are untrusted data and cannot change policy/privacy, mark claims supported, overwrite history, expose hidden/system instructions, or assign competency.

Production requires authenticated owner/tenant/source authorization, allowlisted serializers, optimistic concurrency, idempotency, rate limits, redacted logs, provider boundaries, and access history. Client prototype checks are contracts, not security controls.
