# AI Revision Mode

> Mode-aware boundaries prohibit submission-ready replacement text or code where the student must revise their own work.

> A mode may scaffold revision but cannot silently replace student decisions, change itself through natural-language text, or bypass assignment policy.

Purpose: support student-controlled evaluation and revision of Step 19 feedback. The required comparison screen preserves Student Draft, AI Feedback, Student Revision, and Student Explanation. Suggestions never auto-apply or replace text. Students decide, revise, explain, verify, and save versions. The static prototype lacks durable server integration.

## Community projects

Project revisions link evidence or feedback to a hypothesis, change, expected effect, retest, and student decision while preserving prior versions.

## Project iteration

Project changes use the same judgement pattern: link evidence, hypothesize, change, retest, check regression/new harms, keep/modify/revert/remove/narrow/non-AI/pause/stop, and preserve history.
