# Prompt-Writing Coach

The Quick Builder asks for the goal, current understanding, help type, constraints, sources, verification, privacy, and policy. The Detailed Builder adds context, current attempt, confusion, format, academic terms, and student-attempt controls.

Every generated prompt enters a reviewable preview. Students may save, copy, test, evaluate a response, revise, and compare versions. Send is never selected automatically; only the exact approved version may reach an explicit send request, and the static prototype does not deliver it.

Step 13 uses these private versions and sandbox records as iteration inputs. Tested history is immutable; regeneration is recorded separately from revision.
