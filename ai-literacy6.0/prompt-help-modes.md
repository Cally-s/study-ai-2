# Prompt Help Modes

Supported modes include Hint, Guiding Questions, Concept Explanation, Quiz, Draft Feedback, Source Verification, Code Debugging, and Bilingual or Accessibility support. Modes map to deterministic student-attempt rules.

Hint and Quiz wait for a response; Draft Feedback is limited to student-created work; Code Debugging preserves the student’s structure and reasoning. Active-assessment and assignment-policy restrictions take precedence.
