# Prompt Response Review

Students review relevance, level, help-mode and attempt-rule compliance, constraints, academic terms, format, source transparency and support, verification, uncertainty, privacy, policy, and ownership.

Each dimension is Met, Partly Met, Not Met, Not Applicable, Needs Verification, or Insufficient Information. There is no global response or prompt score.

Step 13 expands review into prompt, response, and task diagnoses and preserves each review rather than overwriting it after revision.
