# Revise, Compare, Verify

## Purpose and learning goal

This Apply-level lesson teaches students to review an AI response, diagnose prompt/response/task problems, revise with a stated hypothesis, compare versions, verify important information, and choose an appropriate next step. Application Skills is primary; Human Accountability, Human Agency, Safe and Responsible Use, AI Foundations, and introductory Iteration and Feedback Loops are secondary.

## Cycle and phases

The cycle is Write → Review the Output → Identify What Is Missing → Revise the Prompt → Compare the New Output → Verify. The lesson retains Learn, Observe, Practise, Explain, Apply, and Reflect.

## Known limitations

The static implementation uses in-memory state and deterministic fixtures. It does not provide durable storage, live model/source tools, production authorization, or automatic competency decisions.

Step 14 provides the claim/source verification path used after iteration when factual support remains unresolved.

## Step 18 — AI Brainstorming

Regenerating brainstorms creates a new immutable run only after the student identifies what was missing; it never overwrites prior seeds.

## Step 19 — AI Feedback

Step 19 preserves every draft and feedback version; each student revision creates a new draft version rather than replacing history.

## Step 20 — Revision With Judgment

Step 20 preserves original, feedback, revision, explanation, and verification versions and never assumes the newest version is best.
