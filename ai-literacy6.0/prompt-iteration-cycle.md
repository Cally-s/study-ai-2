# Prompt Iteration Cycle

Write a reviewed prompt version. Review the output against the learning goal. Identify missing, excessive, irrelevant, unsupported, unclear, or noncompliant content. Revise with a reason and expected effect. Compare prompt and response versions for improvements and tradeoffs. Verify important facts, sources, calculations, quotations, code, current information, or translation meaning. Then accept, revise, split, use another tool, ask a person, or stop.

Viewing a stage never completes it, and every earlier stage remains reviewable.
