# Source Comparison Accessibility

The workspace uses keyboard controls, semantic headings/tables/cards, visible focus, announced agreement/disagreement/weight labels, and stacked narrow-screen card alternatives without horizontal scrolling. It supports 200% zoom, approximately 320 CSS pixels, forced colours, Reduced Motion, RTL, text-only, and Low-Bandwidth modes.

Listen never autoplays; Speech-to-Text is editable and privacy-reviewed. Language Bridge preserves distinctions such as weight versus score and no decisive source versus failed research.
