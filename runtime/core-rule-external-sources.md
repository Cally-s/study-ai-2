# Core Rule: External Sources

`EXTERNALLY_VERIFIABLE_CLAIM_REQUIRES_SOURCE` covers current information, office-holders, products, laws/policies, schedules/prices/statistics, historical/scientific/research facts, quotations, named sources, dates/publications, uploaded documents, and public project claims.

The Step 66 source flow uses privacy-minimized retrieval, then confirms existence, identity, author/organization, publisher, date, currentness, relevant content, and exact claim support. Search snippets are not sources. The source record never implies claim support by itself. If verification fails, the candidate claim is removed or labeled unverified; cached/offline work remains pending internet access.
