# AI Coach Coaching Generation

Step 8 creates a content-minimized generation contract containing mode, permitted assistance, capability boundary, attempt status, task/policy state, source instruction, terminology, presentation, question/hint limits, tools, and schema version. Only the sanitized student-confirmed message reference enters this stage.

The model produces an ephemeral candidate and claim inventory. The candidate is not displayed, evidence, or an `AIResponseRecord`. It contains no chain of thought, hidden answer, policy decision, or invented citation. Mode behavior and final-answer restrictions are enforced in trusted instructions and server validation. Prompt and tool content remain untrusted.
