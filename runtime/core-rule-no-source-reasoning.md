# Core Rule: No-Source Reasoning

`NO_EXTERNAL_SOURCE_EXPLAIN_REASONING` applies to mathematics, logic, feedback on student writing, supplied-content analysis, creative examples, and other tasks with no external factual claim. The Sources section is never empty: it says that no external source was used or that only supplied content was used.

The response explains a reproducible verification method—such as recalculation, substitution, a counterexample, comparison with the supplied passage, or a clear writing criterion. It does not disguise unsupported factual knowledge as “reasoning.”
