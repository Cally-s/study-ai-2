# AI Literacy Competency Progress Map

> Step 28 produces student-reviewed evidence candidates only. Step 3 remains authoritative; no ethics, impact, sustainability, or deployment score is introduced.

The private map reuses the Step 1 four dimensions, three levels, and 12 competency blocks. It shows evidence-based status, supporting evidence, explanation, next action, and history. Page opening, media use, time, prompts, clicks, and AI output never count as evidence.

It is deterministic and works without generative AI. This static prototype uses memory and client contracts; production server authorization and persistence are not available.

Structured lessons generate student-reviewed evidence candidates only. Lesson completion never directly changes competency status.

What-AI-Is candidates map to AI Foundations/Human Agency and optionally Application Skills; the progress engine evaluates them.

# Step 7 evidence

# Step 8 evidence

# Step 10 evidence

# Step 11 evidence

Policy-source and clarification work may create Human Accountability, Safe and Responsible Use, Human Agency, and Application Skills candidates; completion cannot assign status.
# Prompt Coach evidence

Step 12 may nominate reviewed prompt building, testing, verification, response evaluation, revision, and explanation as evidence candidates. Prompt length, count, or completion never changes competency status.

# Prompt iteration evidence

Step 13 may nominate diagnosis, hypotheses, version comparison, tradeoffs, verification, and stop decisions. Iteration and Feedback Loops evidence is introductory only; no status changes automatically.

# Answer-verification evidence

Step 14 may nominate claim decomposition, evidence/source decisions, disagreement analysis, revisions, uncertainty, and versioned records. Completion never changes competency status automatically.

Step 15 may nominate claim-specific metadata/evidence/limitation/independence/weight decisions; no status changes automatically.
