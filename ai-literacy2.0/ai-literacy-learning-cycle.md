# Student–AI Learning Cycle

Every module follows this ordered, reusable cycle:

1. Student attempt
2. AI-guided support
3. Verification
4. Student revision
5. Student explanation
6. Reflection and disclosure

Expanded support requires a student contribution. Steps cannot be skipped. Completion requires a student explanation and reflection; an AI output alone is never sufficient. Sessions can pause, resume, reset progress without deleting the account, and use idempotent saves.

The diagnostic applies the same learning orientation: initial response, educational feedback, optional revision, student choice, and reflection without grading.

Completed cycle artifacts become candidates only when meaningful contribution, verification, explanation, provenance, and integrity requirements are present.

Lessons apply the cycle through Learn, Observe, Practise, Explain, Apply, and Reflect while preserving student attempt, verification, revision, explanation, and disclosure principles.
