# Recovery First Action Standard

Allowed types are confirm due date, open instructions/review material, identify one topic, review one example, list one question, draft a teacher question, start a short block, organize one course, save/pause or request human help.

Deterministic rules run first. The action must fit reported minutes, cite only authorized/confirmed context, require confirmation, require no sharing, avoid graded-work completion and active-test answers, invent no deadline/acceptance and contain no shame/all-nighter language.

No-time produces Save and Pause. Unknown due information produces one-course deadline confirmation. Test concern opens one review source; confusion identifies one blocking step. “Why is this the next action?” provides a concise time/source rationale without scores, prompts or chain-of-thought.
## Inventory boundary

Creating the first action does not add every due item, finalize priority or schedule work. Step 4 opens as a separate private collection phase. Inventory entries may later inform prioritization, but they never retroactively change the Step 3 action or official academic records.
