# Dashboard — Today

Today shows Today’s Minimum Plan, one eligible next action, clear time, observable definition of done, and Start This Action. At most two ready alternatives appear. Eligibility requires confirmed/current/actionable work, prerequisites/materials/instructions/dependencies, capacity without buffer/stopping-time violation, integrity clearance, and no completed/superseded/outdated/hidden Stretch state.

Start revalidates source versions and safety/integrity but starts no timer, completion, submission, message, approval, booking, or buffer use. Partial progress remains saved. Minimum completion says the student may stop; Finish for Today is valid even when no safe action fits.

This workflow consumes the versioned five-band priority decision only after exclusions and hard gates.
