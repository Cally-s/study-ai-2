# Recovery File Retention and Deletion

Each file shows identity, type, size, upload/source, sensitivity, retention, access/shares, extraction, thumbnail, embedding, translation/audio/print/offline derivatives, and deletion state. Supported retention is Use Once, Session Only, selected expiry, Until Deleted, School Policy, Legal Hold, or Unknown; indefinite retention is not default.

Eligible deletion removes active source, extracted/OCR text, thumbnails, previews, embeddings/vector entries, translations, audio, print/offline copies, caches, and temporary files. Pending derivatives and backup expiry remain visibly distinct. File shares require malware scanning, ownership checks, verified recipients, private storage, and short-lived links—never permanent public URLs.
