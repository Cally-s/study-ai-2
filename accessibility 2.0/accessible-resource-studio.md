# Accessible Resource Studio

Step 24 extends this same workspace and issue state with Quick, Full Pre-Publish, Targeted, Batch, Platform and Scheduled modes; no second checker or readiness database is created.

## Purpose and roles

Step 23 provides one batch-oriented workspace for authorized teachers, verified tutors, accessibility reviewers, content reviewers, and administrators. Browser roles are advisory only; production must derive authority server side. Tutors remain limited to verified subject, grade, relationship, ownership/grant, session and organization scope and cannot publish official teacher resources.

## Workflow

Creators select one or many resources, run advisory checks, review severity/status counts, select eligible issues, generate unpublished drafts, review drafts, preview resources, re-run checks, resolve or document issues, and request publication of the exact approved source version. Existing plain-language, translation, vocabulary, print, audio, low-bandwidth and privacy systems are integration targets rather than duplicates.

## Limitations

The static prototype has no trusted roles, CMS, media provider/editor, AI provider, server review queue, learner grant service, publishing backend, or real browser scanner.
