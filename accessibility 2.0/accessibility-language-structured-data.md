# Accessibility and Language Structured Data

> Step 65 canonical mapping: profiles retain student-selected language, reading presentation, and accessibility-profile references without inferring disability, age, or ability. Session and evidence records snapshot the applicable accessibility support without lowering evidence standards.

Schema `accessibility-language-bridge/1.0` defines capabilities, private preference profiles, independent language dimensions, canonical terms/translations/pronunciation, coverage, adaptations/equivalence, activity contracts, user state, STT sessions, captions, transcripts, print snapshots, audio summaries, and issue reports. AIResponseRecord `1.6` adds nullable accessibility and language presentation metadata. Server-owned references/validation exclude diagnoses, ability/reading/age scores, raw audio, private content, and hidden answers. Versions are immutable after publication.
