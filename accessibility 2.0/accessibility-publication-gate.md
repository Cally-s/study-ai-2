# Accessibility Publication Gate

Publication requires a current Full Pre-Publish run matching the exact server-loaded resource version and content hash, active policy version, resolved policy blockers, approved draft fixes, completed required human reviews, valid exceptions and authorized actor. Browser-supplied pass state is ignored. A transaction must re-read the version/hash immediately before publishing to prevent Version 10 results from publishing Version 11.

Preferred wording: “No unresolved automated blocking issues were found. Required human accessibility review must still be completed.” No compliance guarantee is permitted. Scheduled rechecks follow rule, policy, platform and media changes.
