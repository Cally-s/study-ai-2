# Accessibility Check Evidence Standard

Evidence may reference privacy-safe element IDs/selectors, asset IDs, screenshots, sanitized DOM excerpts, heading outlines, focus sequences, contrast values, file metadata and provider errors. It must identify source version/hash, rule/scanner/policy version, method and location. Hidden answers, active tests, test-bank data, private notes, safety/fraud records, diagnoses, accommodation documents, transcripts, recordings and complete learner profiles are excluded. Production retention must be policy configured.
