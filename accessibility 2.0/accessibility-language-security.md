# Accessibility and Language Security

Operations authenticate session identity and authorize tenant, role, activity, content, adaptation, term, translation, profile, and version. Teacher/AI drafts cannot publish without server capability, term, semantic, policy, source, privacy, hidden-answer, caption/transcript, and alternative validation. Prompt/retrieved content cannot override contracts. STT defaults to no raw audio; profiles and playback state are private; account switching isolates state. Logs/events omit diagnoses, student content, audio, age/ability/integrity signals, and discipline.
# Step 64 package boundary

Offline projections are signed/versioned, contain no private profile details, and preserve all required alternatives. Installation verifies content hash, signature, rights, size/decompression paths, and tenant access. STT raw audio is never queued. Package text cannot override pending-verification, policy, safeguard, privacy, answer, or synchronization state.
