# Source-Verification Challenges

Challenges use trusted sources or sources clearly labelled as fictional. Learners distinguish source identity, authenticity, currentness, relevance, and exact claim support. Answer keys and scoring guidance remain server-side; the student view exposes only the intended evidence and instructions.

## Step 57 use
Assessment scenarios reuse Step 43 outcomes and require reasoning about the verification action. Search snippets and invented citations are blocked; fictional sources carry both practice-only labels; unavailable sources pause evidence rather than imply a conclusion.
