# Teacher Lesson Tools Structured Schema

Schema identifier: `teacher-lesson-tools/1.0`.

Records contain identifiers, tool type, owner, organization/course scope, authorized courses, target competencies, content, source/version links, AI-assistance disclosure, review flags, state, timestamps, and audit metadata. States are `DRAFT`, `VALIDATED`, `PUBLISHED`, `ASSIGNED`, `ARCHIVED`, and `SUPERSEDED`. Strict validation rejects unknown fields and prohibited inference or automated-decision fields.
