# Recovery Visual Accessibility

Shared profile/toolbar controls text size, line/letter/word/paragraph spacing, content width, alignment, fonts, dyslexia options, reading ruler, current-line highlighting, contrast and simplified layout independently. Recovery supports High-Contrast Light/Dark, forced colours, visible text/icon statuses, 200% zoom, large/extra-large text and ~320px reflow. Cards/bilingual sections stack, controls wrap, fixed UI does not cover content, ordinary text avoids horizontal scrolling, and tables have text/card alternatives. Manual visual evidence remains NOT RUN.
