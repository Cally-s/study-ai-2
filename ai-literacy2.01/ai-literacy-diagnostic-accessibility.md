# Diagnostic Accessibility

The UI presents one question per screen using headings, labelled fieldsets, native controls, visible focus, live feedback, skip-to-content, keyboard buttons, and text navigation progress. It needs no dragging, hover, camera, microphone, audio, video, colour perception, animation, or time pressure.

CSS supports 320-pixel reflow, forced colours, Reduced Motion, high contrast, RTL, text-only, and low bandwidth. Listen never autoplays. Speech-to-Text is an optional editable transcript that requires intentional submission; raw voice is not retained. English is implemented; Mandarin and Arabic are fixture-ready, not verified translations. Manual assistive-technology testing remains not run.
