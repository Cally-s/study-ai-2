# Diagnostic Security

The domain contract checks identity, tenant/owner keys, capabilities, definition/item versions, response option IDs, optimistic row versions, idempotency, sanitization, and privacy-safe errors. Student item serializers omit accepted-answer rules. Student text cannot change evidence rules, recommendations, pathway availability, sharing, or classifications.

These are client-side prototype controls, not production security. Add authenticated server authorization, durable tenant isolation, rate limiting, encrypted storage, audited configuration, real offline reconciliation, and security testing before release.
