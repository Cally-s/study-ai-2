# Competency Portfolio Items

- **Prompt Revisions:** private details removed; AI suggestions and student decisions labelled.
- **Claim–Evidence Maps:** citations, support state, unresolved claims, and limitations preserved.
- **Source Comparisons:** identity, approval, currentness, and exact support remain distinct.
- **Corrected AI Answers:** original AI text, student correction, checked sources, and remaining limits distinguished.
- **Integrity Scenarios:** only owner-approved releases or student-created learning summaries.
- **AI Use Receipts:** only student-approved shareable snapshots; prompts/conversations/accessibility use excluded.
- **System Cards:** selected submitted, secret-free versions only.
- **Fairness Evaluations:** public/synthetic/approved/anonymized data without sensitive inference.
- **Prototype Versions:** selected safe static/sandboxed versions with iteration explanations.
- **Ethical Reflections:** private by default with additional broader-share review.
- **Community Feedback:** invitation-based, consented display only; no public comments or ratings.
