# Competency Portfolio Sharing

## Step 60 verification
Public badge verification uses the Step 59 privacy-reviewed immutable sharing path and exposes only student-approved verification data. It never exposes full evidence, reviewer contact, private receipts, or unrelated portfolio items.

Visibility is item-level and supports Only Me, named reviewers, teacher/course/school audiences, authenticated/password links, anyone-with-link, and Public Web where eligible. External sharing uses an immutable sanitized snapshot of explicit sections, items, and exact versions—not live private references. Future edits require a new snapshot. Students preview and confirm, choose downloads/identity/expiry, and receive the external-copy warning. They can expire, revoke, remove, or correct a snapshot without deleting private source or institutional evidence.
# Step 62 audience resolution

Resolve the safeguard snapshot before showing audiences. Younger defaults preserve private and teacher/school-authenticated snapshots while hiding Public Web and Anyone with the Link. Student confirmation and configured approvals remain required. Transitions revalidate active shares prospectively without deleting private items or evidence.
