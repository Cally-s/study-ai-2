# Recovery Dashboard Prioritization

The deterministic selection engine applies lexicographic precedence: safety replacement; authorized active-assessment support; required plan review; teacher response/decision; blocker resolution; prerequisite repair; Test Tomorrow preparation; current required work; nearly complete accepted work; selected support review; optional check-in; Finish for Today.

Stretch, stale/unverified work, blocked/waiting/dependent tasks, missing materials, unknown acceptance, protected buffer, post-stopping-time work, and AI completion are suppressed with reasons. An unconstrained AI model never establishes authoritative status or priority.
