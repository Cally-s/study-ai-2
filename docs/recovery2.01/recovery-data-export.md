# Recovery Data Export

Eligible Recovery data can be previewed for Accessible HTML, plain text, JSON, suitable CSV, optional PDF, and selected-file ZIP. The preview shows included/excluded data, approximate size, protection option, link expiry, and device warning.

Exports exclude secrets, tokens, hidden staff notes, other students’ data, internal prompts, private chain-of-thought, credentials, and unauthorized restricted records. Downloads require authentication and short-lived links and are audited.
