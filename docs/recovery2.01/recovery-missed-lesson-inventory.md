# Missed Lesson Inventory

Each record stores course, exact local date, period when known, attendance state, lesson title, source, source version, verification and confidence. `MISSED`, `PARTIALLY_ATTENDED`, `ATTENDED`, `CANCELLED`, `NO_CLASS`, `SCHEDULE_UNKNOWN`, `ATTENDANCE_UNKNOWN` and `CONFLICTING` stay distinct. Cancelled and no-class records are excluded; unknowns become clarification items. A private correction recalculates only affected courses and never edits the official attendance system.
