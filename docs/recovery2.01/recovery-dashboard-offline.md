# Recovery Dashboard Offline

Offline mode shows the latest user-scoped saved snapshot with exact last-updated time and OFFLINE_CACHED freshness. It permits reading, printing, Save and Pause, and private drafts; action Start requires revalidation.

Teacher messages, tutor requests, check-ins, and plan revisions remain drafts. Reconnection checks versions/conflicts, preserves edits, deduplicates events, never broadens sharing, and never automatically communicates, books, or activates a revision. Stale data is never presented as current.
