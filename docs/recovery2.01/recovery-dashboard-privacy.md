# Recovery Dashboard Privacy

“Your Recovery Dashboard is private by default. It is not automatically shared with teachers, parents, tutors, counsellors, or administrators.” External serializers are empty. School-managed governance is disclosed without turning technical capability into routine access.

Sensitive reasons, responsibilities, appointments, emotions, safety/integrity records, diagnoses/profiles, message bodies, tutor/parent notes, conversations, and metrics details are absent. URLs use opaque IDs; ordinary analytics/logs contain events and source metadata, not content. Shared-device state uses generic previews and logout cleanup contracts.
