# Recovery Metrics Privacy

The dashboard, events, corrections, snapshots, and history are private by default. Parent Summary may include only separately selected factual items; teachers, tutors, counsellors, accessibility staff, public profiles, notifications, logs, and ordinary analytics receive no identifiable metric values. Aggregate program analytics require minimum-cell suppression and no re-identification. AI-provider input is minimized. Metrics cannot affect grades, discipline, matching, service hours, Help Credits, fraud, integrity, safety, or advertising.
