# Lower-Priority Deferral

When work does not fit, remove incomplete Stretch first, then optional enrichment, lower-priority review, non-blocking accepted backlog, later-deadline work, and work less valuable than current-unit access. Essential prerequisite/current-unit/Test Tomorrow/teacher-decision/current required/imminent-assessment actions are protected.

Deferral removes work from the active private schedule; it does not delete, complete, reject, or permanently hide it. A collapsed review shows reason/status/teacher need/date and restoration. Urgent unfitted work stays visible and never moves to Stretch.
