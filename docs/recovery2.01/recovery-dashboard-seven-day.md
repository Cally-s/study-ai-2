# Dashboard — Seven-Day Plan

The week shows seven exact dates, current day, realistic focus blocks, important confirmed/proposed deadlines with status, zero-to-three Minimum actions per day, collapsed Optional Stretch, no-capacity days, and protected buffer that is never treated as schedulable time.

It summarizes rather than scheduling every minute. Passed-date work is classified as Ready, Ask First, Waiting, approved deadline, Submitted, Returned, No Longer Required, Replaced, or Consider Releasing. There is no Overdue section or count; Review Older Work is a quiet drill-down.
## Step 36 Recovery Output integration
The Recovery Output aggregates this source into a private, reviewable, versioned student view. Confirmed/estimated/unknown/conflicting/stale status, five-category triage, feasibility, Minimum-before-Stretch, protected buffer, help, review and no-automatic-action rules remain authoritative.
