# Dashboard — Progress

Progress shows Tasks resolved, Work submitted, Prerequisites repaired, and Help requested using Step 29 definitions. Values may overlap and are not summed into a score or percentage. Submitted remains distinct from Accepted; Addressed remains distinct from Resolved; reopened current work does not erase historical progress.

No comparison, rank, streak, points, grades, predictions, privacy choices, dashboard visits, or timer endings become progress. Empty copy recognizes clarification, help-seeking, and small actions without pressure.
## Step 36 Recovery Output integration
The Recovery Output aggregates this source into a private, reviewable, versioned student view. Confirmed/estimated/unknown/conflicting/stale status, five-category triage, feasibility, Minimum-before-Stretch, protected buffer, help, review and no-automatic-action rules remain authoritative.
