# Pause Before You Prompt

> Step 40 can offer personal-information redaction before a permitted provider call and preserves group/private drafts locally when authorization is missing.

This six-phase Understand lesson teaches minimum-necessary disclosure before AI prompts/files. Embodied Ethics is primary; Safe and Responsible Use, Human Agency, Human Accountability, and Application Skills are secondary. A 2–4 minute first-use orientation precedes free-form use without blocking starter prompts, accessibility, navigation, privacy information, or human safety support. Just-in-time preflight, redaction, final preview, configuration transparency, cancel, and secure-channel alternatives protect submission. The static prototype has no real provider or file parser.

## Data Plan Gate

Raw data must not be sent to AI merely to determine safety. Use filename/type/size, manual schema, local or restricted metadata preflight, and student description while unresolved.
