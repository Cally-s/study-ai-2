# Prompt Coach Accessibility

The Coach uses labelled fields, semantic headings, keyboard controls, visible focus, announced readiness findings, text-only presentation, stacked narrow-screen layouts, and no required dragging. It supports 200% zoom, approximately 320 CSS pixels, forced colours, high contrast, Reduced Motion, and RTL.

Reading-level controls, Language Bridge, Text-to-Speech without autoplay, editable Speech-to-Text transcripts, and one-question Low-Bandwidth presentation do not reduce student ownership or alter policy, verification, or attempt rules.
