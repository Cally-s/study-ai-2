# Prompt Iteration Offline

Cached Climate fixtures/scenarios, synthetic outputs, local hypotheses, revisions, comparisons, reflections, and deterministic feedback may work offline. Live tests, sends, current-source checks, and current policy confirmation do not.

Reconnection validates lesson/scenario/template/policy/provider versions, reruns privacy preflight, preserves immutable history, prevents duplicate tests/sends, isolates accounts, and requires review before external testing.
