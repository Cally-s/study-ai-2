# Prompt Version Comparison

Semantic prompt diffs identify added, removed, changed, and unchanged content plus privacy redactions, policy adjustments, and attempt-rule changes. Response comparisons use goal, audience, help mode, relevance, factual support, sources, verification burden, efficiency, ownership, privacy, policy, accessibility, and cognitive load.

Comparisons record improvements, regressions, tradeoffs, unresolved issues, and attribution uncertainty. Character count and response length are never the only criteria, and no global score is created.
