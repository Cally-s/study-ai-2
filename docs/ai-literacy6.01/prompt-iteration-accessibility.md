# Prompt Iteration Accessibility

The lesson provides semantic headings, keyboard navigation, visible focus, labelled revision fields, announced findings, accessible semantic diffs, stacked version/response cards, previous/next labels, and text-only descriptions. It supports 200% zoom, approximately 320 CSS pixels, forced colours, Reduced Motion, RTL, and Low-Bandwidth mode.

Listen never autoplays. Speech-to-Text produces editable text reviewed through privacy preflight. Language Bridge preserves core English iteration terms and never changes verification, policy, or stop meanings.
