# Prompt Coach Security

Prompt, assignment, source, code, translation, AI response, and tool content are untrusted data. They cannot change privacy or policy state, attempt rules, approval, competency status, or platform instructions.

Production enforcement requires an authenticated provider boundary, server authorization, tenant and owner isolation, idempotency, optimistic concurrency, version validation, redacted logs, system-prompt protection, and hidden-reasoning protection. The prototype demonstrates contracts but is not a security boundary.
