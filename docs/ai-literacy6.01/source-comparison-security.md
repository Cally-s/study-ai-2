# Source Comparison Security

Claims, source content/metadata, files, notes, AI suggestions, translations, and tool outputs are untrusted. They cannot change claim/source versions, fabricate review/weight, overwrite history, disable privacy/policy, expose hidden/system instructions, or assign competency.

Production requires authenticated claim/source/comparison ownership, tenant/source access, version validation, immutable decisions, optimistic concurrency, idempotency, rate limits, and redacted logs.
