# Youth Transit Program Source Comparison

The synthetic claim says a discounted pass increased weekday student ridership by 18%. Source A is an older city scan-count table directly supporting the measured-period figure but not causation. Source B is a mixed university working paper with transparent methods but a small self-reported sample. Source C is one student’s firsthand blog experience that repeats 18% without evidence.

Source A normally carries the most weight for the specific statistic, B supporting weight for experience/mechanisms, and C contextual weight only. A careful revision attributes the reported 18% card-use increase and states that causation is not established.
