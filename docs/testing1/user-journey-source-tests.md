# User-Journey Source Tests

UJ-012–UJ-021, UJ-026, and UJ-048 distinguish source existence, identity, metadata, currentness, relevance, exact claim support, citation permission, and claim-support status. A real on-topic source without exact support remains `UNSUPPORTED`; a snippet cannot become a confirmed source; mathematics records `SOURCES_NOT_NEEDED`; cached offline evidence remains pending until online verification.
