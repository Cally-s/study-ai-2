# User-Journey Accessibility Tests

UJ-030–UJ-033 and UJ-050 assert academic-rule equivalence for accessibility-only support, keyboard use, TTS, and bilingual display. Keyboard flow requires no pointer; TTS does not autoplay; English academic terms remain present; presentation preferences do not infer age or diagnosis; and accessibility use does not create receipts, reduce evidence, or alter safeguards.

These are contract-level tests. Real accessibility-tree, screen-reader, STT device, 200% zoom, forced-colour, and manual assistive-technology testing are unavailable and remain release blockers.
