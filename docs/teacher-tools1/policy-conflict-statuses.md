# Policy Conflict Statuses

Exact workflow labels: No Conflict; Policy Reminder Shown; Student Changed Request; Possible Conflict — Context Needed; Teacher Review Requested; Resolved. Valid transitions follow reminder → changed request/context → optional configured review → resolution. These are workflow states, not guilt. Resolved includes a neutral student-facing summary and may mean no conflict, clarification, changed request, confirmed exception/accessibility, corrected error, or referral to a separate process.
