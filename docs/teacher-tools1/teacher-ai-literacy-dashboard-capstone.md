# Dashboard Capstone

Capstone progress shows milestones, evidence, feedback, fairness/accessibility evaluation, iteration, limitations, and required human review across the full project sequence. A justified non-deployment decision is valid progress. The capstone is never reduced to one score or used as an automatic competency certificate.

## Step 56 integration
Teachers may review only intentionally submitted or shared System Cards and Capstone reflections. Reviews are separate records and never edit originals, infer sentiment or honesty, diagnose, rank, automatically grade, or update competency.
