# Teacher Lesson Tools Accessibility

The workspace uses semantic headings, labels, keyboard-operable controls, visible focus, status text, error summaries, and non-color status cues. Content validation requires an accessibility review. Student activities support plain language, adaptable timing, captions or transcripts where needed, screen readers, reduced motion, and equivalent non-AI paths.
# Step 62 profile previews

Teacher tools can preview published safeguard profiles with clear student-preview labeling. Preview never changes teacher identity. Teachers may combine short chunks without removing pause points, preserve accessibility/language supports, and add stronger protections; they cannot infer age, weaken higher-level safeguards, approve their own public-share bypass, or publish policy through AI output.
# Step 63 publication contract

Every teacher-created or AI-assisted activity must pass the shared versioned activity contract, required-term coverage, semantic equivalence, keyboard/screen-reader, media transcript/caption, print/audio, complex-content alternative, policy/source, privacy, and hidden-answer checks. Teachers may save drafts but cannot publish critical failures or approve machine translations automatically.
