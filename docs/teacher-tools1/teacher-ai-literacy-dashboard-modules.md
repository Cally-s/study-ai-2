# Dashboard Modules

Teachers may assign or reassign AI Literacy modules as required, recommended, or optional, set an evidence requirement and due date, preview the student view, and review intentionally submitted results. Opening, viewing, time, prompts, or completion streaks do not demonstrate competency and are not used for ranking.

## Step 56 integration
`Assign Specific Competency Lessons` references existing module and competency IDs. A teacher validates and publishes a version before separately assigning it; assignment never grants competency automatically.
