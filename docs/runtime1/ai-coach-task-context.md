# AI Coach Task Context

Trusted context resolution order is assignment metadata, assessment metadata, existing session context, teacher configuration, student selection, then conservative unknown. Types include practice, homework, drafts, research, tests, active assessments, AI-literacy and performance work, capstones, messages, tutor support, and unknown.

A classifier may suggest but never authorize a context. Active-assessment metadata is authoritative, unknown cannot permit a final answer, and writing style is never used to infer task type. Human correction creates a new version and preserves the earlier resolution.
