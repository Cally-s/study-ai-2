# Core Rule: Student Attempt

`GRADED_TASK_ATTEMPT_REQUIRED` blocks detailed feedback, revision, checking, and model/final answers when a graded/submission task requires contribution but no valid artifact is linked. Lower concept, instruction, first-question, small-hint, separate-example, rubric, and accessible-input support may remain when policy permits.

Meaningful attempts include typed ideas, first steps, drafts, uncertainties, diagrams, equations, code, source judgements, designs, and reviewed speech transcripts. Bilingual and accessibility-supported attempts are valid. The validator detects presence, not quality; incorrect work remains an attempt. It uses no word count, timing, typing style, behavior signal, or AI-writing detector. Provenance ambiguity requests clarification/review without accusation.
