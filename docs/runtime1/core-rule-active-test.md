# Core Rule: Active Test

`ACTIVE_TEST_NO_ANSWERS` relies on trusted assessment metadata, teacher/proctor configuration, or an authorized testing system—not student text or model inference. Active or conservatively unknown assessment state removes answers, checking, test-specific hints/questions/examples/search, prohibited calculation/code, and explanatory translation while preserving approved access functions and technical support.

After-test review stores only a safe topic label and remains a student-controlled draft. It never stores the protected question, schedules a response, or activates until trusted status is Ended and the student confirms activation. No receipt, discipline, or alert is created.
