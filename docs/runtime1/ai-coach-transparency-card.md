# AI Coach Transparency Card

> Step 67 integration: schema `ai-coach-decision/1.1` adds the rule-set version, applicable stable rule IDs, and one neutral student-facing rule summary. Internal trigger configuration, security details, raw content, and non-applicable rule traces remain private.

The card uses these sections when applicable: Learning Mode; Assignment Context; Assignment AI Policy; Why This Type of Help Was Provided; Student Attempt; Response; Sources; Confidence and Reason; Assumptions; What You Should Verify; Your Next Thinking Step; Final-Answer Status; and AI Use Note.

Source states always show meaningful text: no external source used, supplied content only, no reliable source confirmed, or verification pending internet access. The immutable display snapshot contains safe text and references only. Keyboard headings, live status, high contrast, forced colours, 200%/narrow reflow, Reduced Motion, bilingual/RTL, section-level TTS, text-only and print views are supported; print excludes system metadata.
