# Core Rule: Policy Unknown

`POLICY_UNKNOWN_GUIDED_SUPPORT` is neither Allowed nor Not Allowed. It permits clarification, concept explanation, limited hints, guiding questions, structurally different examples, source verification, teacher-question drafting, and accessibility. It denies final/model answers, complete drafts/code, rewriting, and submission-ready work.

The final-answer lock stays active. The runtime neither borrows another assignment’s policy nor predicts the teacher’s likely decision. Unavailable/conflicting policy uses the same conservative fallback and provides a neutral editable question.
