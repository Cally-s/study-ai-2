# AI Response Content Unions

Step 48 uses strict contentType unions for Hint, Guiding Question Context, Similar Example, Reasoning Feedback, Source Verification/Comparison, Draft/Revision Feedback, Code Debugging, Integrity Intervention/Policy Explanation, labelled Model Answer, quiz, and coaching forms. Each variant permits only its required fields. Guiding context cannot contain the final question; model answers require policy eligibility and an AI label; integrity redirection cannot contain prohibited content. Arbitrary HTML is excluded.
