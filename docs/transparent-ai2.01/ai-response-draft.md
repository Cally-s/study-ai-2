# AI Response Draft

AIResponseDraft is untrusted and never displayed. It may propose only response summary, discriminated learning content, confidence reason, material-assumption candidates, verification instructions, one thinking question, AI Use Note/disclosure wording, and student-safe warnings. It cannot provide identity, tenant, context/policy, mode, source IDs/status, confidence level, final-answer permission, verification trust, sharing, versions, IDs, or timestamps. The server rejects unknown fields and composes accepted proposals with trusted context.
