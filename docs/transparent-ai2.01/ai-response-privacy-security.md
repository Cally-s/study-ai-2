# AI Response Privacy and Security

Composition derives user/tenant ownership from authenticated context, uses idempotency, and excludes tokens, prompts, hidden reasoning, private scratchpads, classifier scores, and unnecessary personal/accessibility/safety data. Unsafe fields, injection, and cross-tenant access fail closed. Retrieved content cannot verify itself or alter trusted fields. Production requires durable authorization, encryption, retention/deletion, redaction, optimistic concurrency, rate limits, audits, and isolated caches.
