# AI Response Accessibility

All renderers consume the same validated eight-section record. Semantic headings, sources, confidence/disclaimer, assumptions, separate verification action/outcome, AI Use Note, and final question support keyboard and screen readers. TTS never autoplays; STT requires review. Layout supports 200% zoom, about 320 CSS pixels, focus, 44-pixel controls, forced colours, high contrast, Reduced Motion, print, text-only, bilingual, RTL, mobile, and Low-Bandwidth use without semantic changes.
