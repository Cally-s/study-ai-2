# Recovery Priority Policy

Policy `recovery-prioritization-default` version 1 uses deterministic rule version `transparent-priority-rules-v1`. Urgent means within 24 hours, near term within 72 hours, the planning horizon is seven days, and 90 minutes is substantial work.

Excluded work is separated first. Unknown/conflicting/stale requirements, acceptance, instructions, materials, prerequisites, estimates, teacher decisions, or non-fitting deadlines go to Ask First. Consider Releasing requires an evidence basis. Confirmed actionable urgent work goes to Do Now; confirmed important near-term work to Do Next; later valid work to Schedule Later.

Ordering uses documented category comparators, not a single score. A current inventory, capacity snapshot, feasibility analysis, verification review, policy version, and algorithm version are stored with each analysis. Changes to any source make the analysis Outdated and require recalculation. Provisional analysis preserves every unknown and schedules no substantial uncertain work. Do Now overflow is a notice, not a schedule.

Explanations must match the current analysis ID/version, category and rank. An outdated explanation cannot authorize decomposition, scheduling, release, messaging, export or sharing.
