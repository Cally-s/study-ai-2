# Recovery Speech-to-Text

Every destination retains a normal text field. Microphone use is explicit: permission, recording, draft transcript, review, edit, then Use This Text/Continue Editing/Delete/Cancel. It never auto-starts, submits, sends, books, or changes a plan. States include off/requesting/listening/paused/processing/ready/editing/denied/unavailable/failed/cancelled/deleted with text labels. Disclosure covers purpose, access, retention and deletion. Raw audio defaults to deletion after transcription; edited transcript is private; no emotion analysis or ordinary analytics.
