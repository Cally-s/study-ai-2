# Recovery Sharing Permissions

Every permission has a source, purpose, verified recipient, relationship, scope, action, start, expiry, timezone, and audit event. Default external access is View only, time limited, no download, no print, no reshare, and no permission management.

Full Plan is never default. Immutable Snapshot is default; Live Scoped View requires explicit selection, remains bounded, expires, and is revocable. Preview lists included and excluded information before confirmation. Revocation blocks future StudySpark access and links but cannot erase copies already downloaded, printed, copied, or screenshotted.
