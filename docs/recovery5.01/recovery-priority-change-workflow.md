# Recovery Priority Change Workflow

Change Priority first shows the system recommendation, current selection, material facts, verification constraints, capacity effect, displaced-item notice, protected-buffer restriction and official-status notice. One click cannot apply a change.

Students may select one or more controlled reasons or Prefer Not to Say. Optional free text is sanitized, stored privately, excluded from views/analytics/logs, and never verifies an official fact. The request remains awaiting confirmation until the student reviews and confirms its impact.

Safe changes call the existing Step 9 override—not a second override engine. Substantial provisional Do Now requests are denied; smaller uncertain changes remain provisional. The original recommendation and history remain. Undo/Restore returns the system category/order without clearing importance, deleting history, sharing, sending or changing school status.
