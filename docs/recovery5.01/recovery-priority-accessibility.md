# Recovery Priority Accessibility

The five categories use headings and text, never colour or position alone. Native buttons support Move up and Move down without drag. Focus remains visible; layouts reflow; forced colours, Reduced Motion, RTL, Plain Language, bilingual review and Low-Bandwidth text are supported by source contracts.

Explanations name the recommendation, reason, uncertainty, unlocking action and What Could Change without requiring arithmetic. Changes announce their result and preserve undo/restore. Manual keyboard, screen-reader, zoom, contrast, speech-input, bilingual/RTL, cognitive-access and representative-user results remain NOT RUN.
