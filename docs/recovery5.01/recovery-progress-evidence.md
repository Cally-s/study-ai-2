# Recovery Progress Evidence

Eligible source events require system, authorized-source, student-confirmed, or combined verified evidence with a source entity, version, and dedupe key. Provisional, insufficient, conflicting, stale, invalid, and outdated evidence cannot create completion recognition.

Submission-provider status distinguishes Uploaded from Submitted and teacher acceptance. Teacher-message status distinguishes Prepared, Sent, and Response Reviewed. Tutor booking is never attendance; verified attendance requires the existing attendance record. Plan revision recognition requires approved revision evidence. Unsupported or client-only claims are rejected.
