# Smaller Action After Missed Work

A revised action has a specific verb/object, observable definition of done, explicit stop point, valid dependency/material/teacher-decision state, and capacity fit. It reuses the next incomplete decomposed action when possible and splits only remaining work.

Prerequisite checks reuse existing diagnostics/repair and select the smallest verified concept. Vague “work on it” rollover, full-course remediation, duplicate paths, and reopening completed steps are prohibited.
