# Seven-Day Replanning

Capacity, deadline, status, acceptance, verification, priority, teacher response, repair, material, instruction, horizon, timezone or policy changes invalidate affected scheduling versions. Completed blocks remain saved.

Missed Minimum work triggers a new smallest feasible action; it is not copied wholesale onto tomorrow. Stretch noncompletion never rolls, becomes overdue or creates failure/streak events. Replanning is supportive: “The plan can change. You have not failed.”
