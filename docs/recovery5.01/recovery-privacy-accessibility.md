# Recovery Privacy Accessibility

The Privacy Centre uses native headings, landmarks, fieldsets, labels, buttons, polite status, visible focus, keyboard operation, screen-reader descriptions, 200%/320px reflow, high contrast, Reduced Motion, RTL, Plain Language, bilingual notices, TTS, reviewed STT, Low-Bandwidth, and offline text controls.

Important English terms such as Private, Save, Share, Recipient, Retention, Delete, Access History, Revoke Access, Consent, Permission, Expiry, Live Access, and Shared Snapshot remain visible. Translation must preserve not-shared/shared, possible access, requested/completed deletion, revoked/external copies, guardian authorization, and managed-account meaning. TTS never reads hidden private content.
