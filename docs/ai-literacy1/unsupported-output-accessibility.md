# Unsupported Output Accessibility

The lesson provides keyboard controls, semantic source/claim regions, visible focus, screen-reader reading order, Text-to-Speech without autoplay, Speech-to-Text with editable transcript review, 200% zoom, 320 CSS-pixel reflow, forced colours/high contrast, Reduced Motion, RTL, Language Bridge, and Low-Bandwidth text-first presentation. No mouse, dragging, audio, or colour perception is required.
