# Teach-Back: Own Words

Explain-in-own-words checks show the exact instruction “Do not copy the explanation above.” Students may preserve formulas, source titles, quotations, code identifiers, technical vocabulary, and configured English academic terms while responding in a selected language or accessible format. Accurate synonyms and alternate structures are accepted; grammar is not concept evidence unless taught. Close wording triggers a formative request for an analogy, example, mistake, or transfer—not plagiarism, cheating, honesty, or copying accusations and never a similarity score.
