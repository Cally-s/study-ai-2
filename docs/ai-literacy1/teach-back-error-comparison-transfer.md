# Teach-Back: Error, Comparison, and Transfer

Identify the Mistake uses one clearly labelled, non-accusatory practice error where possible. Compare Two Options presents two accessible, non-colour-only, trusted or labelled-practice choices and asks for one integrated selection/justification. Apply It in a Different Context changes the context while preserving the concept and permits hypothetical responses without private disclosure. Each activity has one primary task, uses verified sources when factual, and cannot leak a restricted answer.
