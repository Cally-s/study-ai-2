# Required Sections

Project name; Purpose; Intended users; Users who may not be served well; Problem being addressed; Why AI is being used; Non-AI alternatives considered; Input data; Data permissions; Model or service used; Expected outputs; Known limitations; Possible errors; Bias and fairness concerns; Privacy protections; Accessibility features; Human oversight; Testing method; Feedback process; Conditions under which the system should not be used.

Each section records current maturity, evidence, uncertainty, and student confirmation. Not applicable requires an explanation.
