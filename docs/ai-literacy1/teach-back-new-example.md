# Teach-Back: New Example

A new example tests the same underlying skill with meaningfully different numbers, wording, data, evidence, code, or context. It remains clearly separate from the assignment, blocks near-duplicate assessment items/test-bank reconstruction, and never exposes the assigned or expected answer in client metadata. Server-held criteria and trusted calculators/code tests/source validators assess the submitted artifact. Active-assessment, competition, policy, ladder, and final-answer restrictions remain controlling.
