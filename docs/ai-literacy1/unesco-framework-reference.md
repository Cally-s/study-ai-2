# UNESCO Framework Reference

StudySpark’s AI Literacy curriculum structure is informed by UNESCO’s AI Competency Framework for Students. StudySpark is not UNESCO-certified or officially endorsed by UNESCO.

The map uses four dimensions—Human-centred mindset, Ethics of AI, AI techniques and applications, and AI system design—and three progression levels—Understand, Apply, and Create—for exactly 12 connected competency blocks. The blocks are iterative, interdisciplinary, revisited across grades, and localizable. No UNESCO logo, certification badge, or official-course claim is used.
