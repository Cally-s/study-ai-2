# Source Types

Types include government data/reports, official policies/school sources, datasets, original research, systematic/meta/scholarly reviews, university reports, peer-reviewed/preprint/conference work, textbooks/reference works, technical standards/docs, original transcripts/publications, news/investigations, expert/organization commentary, blogs, firsthand accounts, forums, AI summaries, student notes, synthetic lesson sources, Other, and Unknown.

Hosting organization, domain, or visual style never establishes type or weight; missing types remain Unknown until reviewed.
