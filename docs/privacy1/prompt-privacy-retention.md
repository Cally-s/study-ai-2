# Prompt Privacy Retention

Raw drafts remain only in the normal authorized private draft store. Ephemeral finding values and offsets expire after the session or material edit. The preflight record stores categories/counts, action, sent state, destination, detector/policy versions, error state, and keyed HMAC references where comparison is required. It never stores the prompt, detected values, replacements, medical or safety content. Cancelled prompts are not retained solely for analytics. No student privacy history or profile is created.
