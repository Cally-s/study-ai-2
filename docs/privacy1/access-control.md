# Recovery Access Control

Authorization combines authenticated actor, subject ownership, tenant/organization, verified role and relationship, resource sensitivity, purpose, governance/age/policy, active scoped grant, expiry/revocation, and exceptional authorization. Role alone never grants broad access. Client or AI state cannot create permission, change recipient, extend expiry, bypass revocation, or trigger sharing from file instructions.
## Step 35 teacher-support integration
Teacher-Supported Recovery uses a verified, course-scoped, expiring request packet and structured response. Only student-selected minimum information is visible; teacher authority, privacy, integrity, accessibility, offline drafts, source versions, student review, and approval-before-plan-activation remain enforced.
