# Age-Safeguard Public Sharing

Younger profiles default to private, teacher-only, course-authenticated, or school-authenticated audiences. Public Web and Anyone with the Link are disabled together; neither can bypass the other. Step 59 remains the sharing engine and requires server eligibility, student confirmation, configured school/guardian review, privacy/copyright review, and immutable sanitized snapshots. A teacher cannot publish for a student. Profile transitions revalidate active shares and invitations prospectively without deleting private portfolios, evidence, or badges.
