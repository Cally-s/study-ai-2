# Prompt Privacy Redaction

Redaction is always initiated by the student. The service creates a revised draft, preserves the original private draft, shows Original Message and Revised Message, lists every change, and supports Undo. Suggested replacements preserve the academic purpose: roles replace names, general areas replace addresses, and general accommodation language replaces unnecessary diagnosis detail. Code blocks, equations, citations, and bilingual formatting must be preserved. Creating a preview never sends it; explicit confirmation is required.
