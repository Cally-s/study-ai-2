# Prompt Privacy Destination Policy

Permission is specific to the current message, destination, purpose, actor, tenant, draft version, detector version, and policy version. The server resolves AI Coach, retrieval, image generation, code sandbox, teacher/tutor/administrator messages, accessibility/safety support, community review, portfolio, and authorized reviewer destinations. Unknown policy fails closed and preserves the draft. **Send Only When Permitted** performs a current check; it never queues future delivery. Public Portfolio reuses Step 59 rules.
