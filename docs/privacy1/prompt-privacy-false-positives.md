# Prompt Privacy False Positives

Context rules protect academic, historical, literary, fictional, and bibliographic text. Jordan normal form, Newton’s law, Mark Antony, May 2026, MHF4U, page and equation numbers, ISBNs, DOIs, cited authors, and public figures are not hard-blocked merely because they resemble names or identifiers. Low-confidence findings remain reviewable. **Not Personal Information** applies only to the current draft and never disables future secret detection. Product feedback may contain only content-free aggregate categories.
