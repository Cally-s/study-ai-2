# Prompt Privacy Accessibility

The semantic dialog uses headings, lists, explicit labels, status announcements, keyboard-operable 44-pixel controls, visible focus, mobile reflow, forced colours, Reduced Motion, and RTL support. Screen readers announce the Privacy Check, finding count, safely masked values, destination, changes, and cancellation. TTS never autoplays. STT produces editable text and never auto-submits; preflight runs after transcript review. Using a screen reader or stating a relevant general accessibility need does not itself create a privacy failure.
