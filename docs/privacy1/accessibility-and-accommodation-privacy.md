# Accessibility and Accommodation Privacy

Step 27 keeps AccessibilityPreferences functional-only and schema closed. Formal accommodations, diagnoses and supporting documents remain separate highly restricted workflows.

Step 23 author previews show functional implementation settings only. Reviewers and creators never receive diagnosis or accommodation documents merely to evaluate resource presentation.

General settings store functional choices, never diagnostic labels. Students can use accessibility features without disclosing a diagnosis. Formal accommodation records and documents belong in a separate highly restricted workflow; implementers receive only authorized functional instructions. Tutors never receive diagnoses or supporting documents by default. AI inputs exclude diagnoses, documents, guardian data, private notes, and unrelated participant content.
