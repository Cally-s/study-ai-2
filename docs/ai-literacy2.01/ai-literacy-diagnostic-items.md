# Diagnostic Items

The eight versioned core items cover privacy, unsupported claims, prompt comparison, verification, assignment assistance, bias, source selection, and honest AI-use disclosure. Each stores its evidence area, competency mapping, response type, options, accepted evidence rules, hint, neutral feedback, reading/language variants, accessibility notes, and version.

Every scenario is synthetic. Items never request real passwords, identification, addresses, medical records, private messages, confidential school data, active-test content, or misconduct confessions. Hidden answer keys are removed from student views.
