# AI Literacy Lab

The Lab is a prominent, student-facing home for learning about AI. Its governing principle is: “StudySpark should help the student remain the thinker, author, and decision-maker.”

The landing page contains Understand, Apply, and Create pathways; six contextual actions; the six-step Student–AI learning cycle; the 12-block competency map; private progress; privacy and Academic Integrity guidance; and a return action on every pathway. It is available from global navigation, dashboard, AI Coach, courses, study rooms, tutoring, and teacher contexts.

The implementation is additive and feature-flagged. It uses in-memory prototype state; production persistence and authoritative server enforcement are not present.

Step 2 adds the optional AI Literacy Learning Check as a prominent starting-point action. Students may skip it and choose any pathway; disabling the diagnostic never disables the Lab pathways.

Step 3 adds a private 12-block Competency Progress Map based on meaningful accepted evidence, never passive activity.

Step 4 adds consistent six-phase lessons and the featured “Why AI Invents Information” lesson.
