# Diagnostic Privacy

Attempts, responses, explanations, hint use, evidence observations, recommendations, selections, and history are private by default. Teachers, tutors, parents, administrators, public profiles, ordinary analytics/logs, and model training receive none of this by default. Teacher preview contains only public structure and feedback.

Students can delete responses and eligible attempts. Deletion removes in-memory responses, explanations, feedback/recommendation snapshots, selection records, and derived indexes while preserving minimal audit metadata. This prototype has no backups; production retention, encryption, access review, export, and backup expiry require server infrastructure.
