# Scenario Assessment Design

Every definition records title, context, target competencies, Understand/Apply/Create level, category, primary task type, prompt, reasoning requirement, response format, resources, policy/source context, missing-context design, three-to-six explicit criteria, valid alternatives, misconceptions, teacher guide, feedback/retry configuration, languages, accessibility metadata, fictional/public status, version, and publication state.

Tasks ask learners to interpret, compare, decide, verify, redesign, or respond—not merely recall definitions. Apply and Create require reasoning; Create requires design, evaluation, production, or iteration. Prompts may ask for the important issue, applicable principle, evidence, missing information, next action, or unsafe assumption without forcing all prompts every time.
