# Scenario Privacy and Security

Drafts are private by default; reviewers see only authorized submissions. Full responses, safety content, diagnoses, private conversations/receipts, answer keys, reasoning internals, keystrokes, and browser activity stay out of analytics and events. Model training is off by default.

Server-style operations enforce identity, role, tenant, course, assessment, student relationship, and scenario/assessment/policy/source/criteria versions. Strict schemas reject surveillance, detector, probability, risk, honesty, dependence, and ranking fields. Protected keys are never projected to clients, ARIA, offline caches, or downloads. Untrusted source text cannot override criteria. Optimistic versions and idempotency prevent overwrite and duplication; account changes isolate drafts.
