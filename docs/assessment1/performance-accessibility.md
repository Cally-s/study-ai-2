# Performance Assessment Accessibility

Briefs, milestones, artifact controls, portfolio, rubric, source panels, diagrams, code/math, tests, feedback, review, recognition, correction, and exports support keyboard, screen readers, visible focus, TTS without autoplay, reviewed STT, accessible diagram descriptions, bilingual/RTL presentation, 200%/320px reflow, high contrast, forced colours, Reduced Motion, mobile, text-only/print, Low-Bandwidth, and offline drafts. Alternate formats retain equal evidence value; raw audio is not retained by default.
# Step 62 safeguards

Performance assessments may use shorter task sets and flexible accessible evidence without changing authentic criteria. Final-answer restrictions remain server enforced. Advanced work, prototype failures, safe no-code alternatives, and Independent Retry evidence remain valid regardless of safeguard profile.
# Step 63 shared contract

Performance tasks preserve full evidence/rubric requirements across accessible math/code/diagram/table/media, keyboard alternatives, reviewed speech, print, language bridge, and reading support. No accessibility tool changes independence, authenticity, evidence validity, prototype eligibility, or badge/portfolio recognition.

UJ-031 and UJ-041 require operable access and student reasoning respectively; neither clicks nor accessibility use becomes competency evidence.
