# Performance Prototypes

Valid prototypes include flowcharts, clickable mockups, paper prototypes, rule-based systems, low-code tools, coded demonstrations, simulated interfaces, and safely sandboxed AI-assisted prototypes. Files/code require malware and secret scanning; execution needs isolation, limits, and approved dependencies. Use public, synthetic, teacher-approved, or properly anonymized data. No public deployment or high-risk/confidential processing is required.
