# Scenario Assessment Rubrics

Rubrics select three to six relevant criteria: issue, policy/principle, evidence, fact versus assumption, missing context, uncertainty, next action, ownership, privacy, source support, affected users, accessibility, unequal harm, oversight, non-AI alternatives, and limitations.

Response-level statuses are Demonstrated in This Response, Applied Independently in This Attempt, Partly Demonstrated, One Idea Needs Repair, Not Enough Evidence Yet, Student Unsure, Teacher Review Required, and Task Invalid. Accurate alternative reasoning is accepted without exact wording or keyword-only evaluation. Missing reasoning normally yields **Not enough evidence yet**. Ambiguous formal evidence requires human review.
