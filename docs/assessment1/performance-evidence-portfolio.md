# Performance Evidence Portfolio

## Step 59 distinction
This remains an assessment-submission package. A Competency Portfolio references selected immutable versions from one or more packages as a longer-term student-controlled presentation layer; it does not expose later revisions or change assessment evidence.

One versioned portfolio contains assessment/type/policy versions, learner or permitted group, competencies, evidence checklist, artifacts, sources and verification, AI contribution, student contribution, feedback/revisions, reflection, receipt reference, submission, review, and recognition states. Artifacts preserve student-created, revised, accessibility-supported, AI-assisted/generated, teacher-template, group, peer, and source provenance. Drafts stay private; submission freezes a version; revisions create successors; accessible export excludes protected material.
