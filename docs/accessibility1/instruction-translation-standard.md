# Instruction Translation Standard

Instruction translation must preserve actions, sequence, conditions, exceptions, warnings, deadlines, quantities, units, interface control names, formulas, code, course terms and source citations. Original English remains visible and authoritative. Candidates must use the original version/contract and pass structured exact plus independent semantic validation.

This prototype has no general instruction translation provider or independent equivalence validator, so only the approved photosynthesis explanation fixture is translated. Active/important assessment instructions require policy authorization and the assessment notice; tested vocabulary/passages, answer choices, hidden answers and teacher-only content are blocked. Official/high-stakes instructions require real human-review metadata.
