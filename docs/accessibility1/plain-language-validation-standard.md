# Plain-Language Validation Standard

Exact validation checks every required term, number, date, unit, equation, name, condition, exception, warning, citation and reasoning element. Active-assessment output is rejected for answer-revealing phrases. Failures map to required-term, fact-coverage, number/unit, equation or assessment-policy status and retain the original.

Independent semantic equivalence, contradiction/qualification entailment and factual verification require an approved provider or human reviewer and are not available here. Therefore exact success never produces an academic-equivalence claim. A future corrective retry may run once against failed IDs; repeated failure must return the original, not fabricate output. Deterministic formatting is the offline fallback only when exact validation passes.
# Step 11 level validation

The same exact-element and assessment validation applies to all four levels and structures. Each candidate is validated against the original contract. Cache reuse requires the same source version/hash. A pass remains a required-element pass, not proof of semantic equivalence or teacher review.
