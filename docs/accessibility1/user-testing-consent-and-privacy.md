# User Testing Consent and Privacy

Participation is voluntary and never affects grades, tutoring, credits, attendance or account standing. A diagnosis is not requested. Tests use no real schoolwork, grades, messages, recordings, transcripts, accommodations or credentials. Optional session recording requires separate granular consent, a non-recorded alternative, recipients, processors, retention, withdrawal and deletion information.

Minor participation requires reviewed assent/authorized-adult policy. Evidence uses privacy-safe participant codes and excludes identifying/sensitive content. Production contact, retention and deletion policy is not configured; therefore representative recruitment/testing must not begin from this prototype.
