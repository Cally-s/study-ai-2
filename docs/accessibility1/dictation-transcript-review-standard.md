# Dictation Transcript Review Standard

Interim results appear only in a labelled, non-live, non-editable preview. Final/reliable partial text moves to one labelled editable textarea. Available actions are Insert Transcript, Append Transcript, Replace Selected Text when applicable, Copy Transcript, Discard Transcript, Start Over, Undo Last Dictation, Try Microphone Again, permission help, and Continue Typing.

The original value, selection, cursor, and field version are captured. A newer-value conflict suppresses replacement and preserves current edits. Unconfirmed text never enters search, notes autosave, moderation, posting, messaging, or submission. After explicit insertion, it becomes ordinary editable draft text and only the destination’s existing explicit action can proceed.
