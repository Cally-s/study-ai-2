# MVP Preference Model

Step 27 replaces the conceptual preference defaults with the canonical validated model/API contract, schema/version fields, legacy mappings and optimistic concurrency. Production persistence remains unavailable.

The minimal functional model contains text size, line spacing, contrast, reduced motion, dyslexia-friendly display, reading ruler, preferred/bridge language, explanation level, captions, transcript-saving choice, speech rate, Low-Bandwidth Mode, Study Room mode and tutor sharing. Device settings apply locally; verified account settings would override organization defaults, while response/conversation overrides remain narrower and temporary.

Diagnosis, disability type, medical information, English proficiency, immigration status, academic ability, financial status and home circumstances are prohibited. Public serializers exclude all preferences. Production requires account-scoped persistence, versioning, conflict handling and policy review.
