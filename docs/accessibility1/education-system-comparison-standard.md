# Education System Comparison Standard

A comparison first requires the student to select the Canadian province/territory/board/institution and identify the other system. It compares concepts, similarities, differences, non-equivalent terms and verification actions; labels official policy separately from common practice; cites reviewed effective-dated sources; and never assumes origin, immigration status, school type or application plans.

The prototype returns context-required prompts and then refuses unsourced mapping. It displays school-system and cultural-comparison notices and never claims equivalence. No reviewed education-system concept registry exists.
