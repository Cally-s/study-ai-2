# Caption Translation Standard

Original and translated tracks are separate versioned records. The original stays available; translated tracks display the automatic-translation notice and identify source/target language. A source correction invalidates dependent translations until regeneration.

No translation provider is configured, so translated and bilingual captions are NOT_AVAILABLE. Future support must preserve math/code/technical terms, direction and language metadata, RTL display, timing relationships, correction ancestry, and a verified language matrix. Interface translation never counts as caption translation.
