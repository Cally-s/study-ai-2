# Journey Test Evidence Standard

Evidence records journey/name, layer, tester/participant code, time, version/deployment/schema/flags, browser/OS/device/AT/input/language/level/display/network/source/account, preconditions, non-empty performed steps, expected/actual outcome, completion, assistance, data loss, privacy, accessibility, performance, authorized screenshots/recordings/tree/network/storage artifacts, issues/severity/retest and limitations.

Pass requires completion, no unapproved assistance, no data loss/privacy leak/Critical issue and required evidence. Passwords, real student data, voice/private messages, diagnoses, accommodations and safety records are forbidden. Evidence retention requires reviewed policy.
