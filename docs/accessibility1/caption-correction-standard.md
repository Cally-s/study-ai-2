# Caption Correction Standard

Students may report incorrect/missing text, speaker, timing, language, technical terms, names, numbers, math, inappropriate output, or another error. A suggestion creates a separate report and never changes an authoritative segment.

Only an authorized reviewer may produce a new corrected version. Preserve the automatic/source version, reviewer/date, supersession link, content hash, audit history, speaker/timing changes, translation invalidation, and stale download invalidation. Human-reviewed wording is prohibited until review actually occurred. The local prototype records reports in memory but has no reviewer workflow.
