# Multilingual Response Control Standard

- **Translate this:** selected-language-only from original; asks for language when absent.
- **Show English and Selected Language:** same-level semantic bilingual view with glossary.
- **Explain the English keywords:** resolves required contract terms through Step 13; never auto-saves.
- **Use simpler English:** explicit split alignment lowers English one level and preserves curriculum/terms/source/selected-language version.
- **Give a bilingual example:** only reviewed assessment-safe fixtures; unsupported requests refuse invention.

Dynamic labels include English and Chinese/French/Arabic/Spanish as selected. All are native buttons with contextual accessible names. Boundaries preserve Level 1 and reject unsupported languages, invalid modes/alignments, active assessments, hidden content and high-stakes AI-only translation. “Save this language and response mode as my default” requires confirmation; ordinary controls are temporary.
