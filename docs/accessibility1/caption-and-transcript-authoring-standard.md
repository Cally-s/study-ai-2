# Caption and Transcript Authoring Standard

Step 24 requires separate human caption/transcript accuracy sign-off. Media changes invalidate automated metadata results and prior approvals.

Caption tracks and transcripts are distinct versioned resources. Production upload must validate authorized media, rights, consent, language, format and size. Editors must preserve original automatic tracks and support timing, speaker labels, overlap/gap correction and keyboard operation. Automatic captions remain unreviewed until a person approves them. Transcript access follows Step 22 privacy and session authorization; no hidden recording is allowed.
