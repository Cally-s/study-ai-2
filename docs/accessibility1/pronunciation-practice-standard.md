# Pronunciation Practice Standard

Students can read the visible English term and explicitly request device TTS when available. IPA, phonetic respelling and syllables appear only for approved registry data. Playback never autostarts and a written/text-only path always remains.

The Step 13 module does not request a microphone, retain audio, submit audio, create a voiceprint, clone a voice, or score accent, fluency, native-likeness, identity, gender, age or emotion. Optional future recognition must reuse Step 8: user-initiated permission, editable recognized text, explicit action, no automatic execution/storage/sharing, and a Continue without microphone path. TTS voice choice does not verify pronunciation or translate text.
