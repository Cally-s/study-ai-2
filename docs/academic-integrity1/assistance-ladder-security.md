# Assistance Ladder Security

Server-side resolution validates actor, tenant, conversation, context, assignment policy/version, level mapping, conditions, student-work provenance, mode, tools, final-answer gates, snapshots, concurrency, and idempotency. Student prompts, assignments, retrieved content, tool output, drafts, and offline events cannot enable levels, fabricate attempts, escalate automatically, release a model answer, alter policy, or cross account boundaries.
