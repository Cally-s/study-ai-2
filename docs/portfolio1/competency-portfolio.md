# Competency Portfolio

> Step 65 canonical mapping: portfolio competency status reads from `AICompetencyProgress`, a rebuildable projection of the append-only competency-evidence ledger. The portfolio does not accept client-authored evidence counts or global scores, and pending offline source checks do not count as demonstrated evidence.

## Step 60 badge display
Awards are private by default. Students decide whether a badge appears in a private portfolio or sanitized share snapshot. Hiding/revoking display never revokes the award, affects recognition, or changes grades.

The Competency Portfolio is a student-curated collection of learning evidence. Students decide which eligible items to include, which versions to present, which audiences may view them, and which items—if any—are shared publicly.

Every portfolio, section, item, note, reflection, receipt, artifact, and share configuration is **Only Me** by default. The exact required item types are Prompt Revisions, Claim–Evidence Maps, Source Comparisons, Corrected AI Answers, Integrity Scenarios, AI Use Receipts, System Cards, Fairness Evaluations, Prototype Versions, Ethical Reflections, and Community Feedback.

Step 58's Performance Evidence Portfolio is an assessment submission package; Step 59 is a longer-term student-curated presentation layer referencing selected immutable evidence. Public sharing is optional and never required for assessment, recognition, grades, graduation, certification, participation, or support.
# Step 64 private offline drafts

Students may organize cached eligible evidence and draft summaries/sharing configuration offline. Pending source checks stay ineligible. No share activates or becomes public on reconnect automatically. Step 59 revalidates evidence, privacy, copyright, audience, consent, safeguard, and student confirmation online. Package expiry never deletes private portfolio drafts.
