# Competency Portfolio Evidence

## Step 60 badge references
Portfolio items may reference immutable awards and verification snapshots, not private applications/packages. Display preserves issuer, scope, definition/criterion versions, review date, limitations, and the public notice without implying completeness or mastery.

Items reference, rather than duplicate, authorized source systems, artifact IDs, immutable versions, ownership/contribution provenance, teacher review, competency evidence, recognition records, citations, and limitations. Student-suggested competency links remain visibly distinct from formally confirmed links. Curation never changes source evidence or recognition and never calculates portfolio quality, authorship percentage, originality, global literacy, or a single score.
