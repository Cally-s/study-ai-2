# Competency Portfolio Security

Share snapshots contain sanitized copies only. Secure token/slug mapping is server-controlled and tokens/passwords are never logged or stored in plaintext. Audience grants use least privilege and immediate revocation. CSP, sandboxed embeds, unsafe-link checks, malware/secret scans, metadata stripping, prompt/retrieval-injection validation, tenant/ownership/version checks, optimistic concurrency, and idempotency protect sharing. Events exclude private content, contacts, secrets, tokens, tracking, risk, and detector data.
# Step 61 request gate

Portfolio AI requests require a server-controlled privacy preflight ID/pass flag, current destination-policy version, draft ownership, tenant isolation, server secret recheck, explicit confirmation, and idempotent dispatch. Direct provider calls are rejected. Privacy findings cannot change competency, badge, review, or award state.
