# Guiding Questions Contract

> Runtime turns contain one semantic task, reference the actual student response, prohibit self-answer/question plans, and stop until another intentional response.

Ask exactly one focused question based on the latest response, optionally explain its relevance in one sentence, then wait. Never answer it in the same turn. Correct, partial, incorrect, and “I do not know” responses lead to one adaptive next question or an explicit mode suggestion, never an automatic switch.
