# Progressive Hint Contracts

Direction names a concept/formula/strategy without performing an operation. Next Step identifies one operation or decision without carrying it out. Guided Setup creates only an initial partial structure with meaningful student work remaining. All `THREE_LEVEL_V2` schemas require no final answer, no complete solution, and `waitForStudent: true`; hidden, teacher-only, redaction, answer-key, proof, code, lab, and submission-ready fields are prohibited.
