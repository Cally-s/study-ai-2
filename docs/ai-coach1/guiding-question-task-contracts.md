# Guiding-Question Task Contracts

Mathematics progresses from givens to concept/formula, operation, verification, then method explanation. Proof asks conclusion, theorem, and reasoning. Multiple choice asks one criterion without revealing the option. Writing asks claim/evidence and preserves authorship. Coding asks behavior, condition, and debugging logic without code completion. Research/source work asks exact claim and support. Labs ask observation and uncertainty. Reflection asks for the student’s own idea. Translation preserves precise terms. AI projects ask design choice and limitation.
