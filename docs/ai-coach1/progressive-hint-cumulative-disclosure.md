# Progressive Hint Cumulative Disclosure

Before each level, review AI-disclosed concepts, operations, transformations, and partial structures plus separately identified student contributions. Hint 2 includes Hint 1 history; Hint 3 includes both earlier turns. At near-complete, complete, or final-answer risk, generate nothing and offer an attempt, prerequisite support, reasoning review, or human help. Store only minimum structured elements and a context hash—never a solution or answer key.
