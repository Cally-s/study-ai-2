# Challenge Task Contracts

Mathematics and proofs use valid in-domain cases and theorem conditions. Multiple choice challenges reasoning without revealing the option. Writing, literature, history, research, and science use supported evidence without writing final prose or conclusions. Coding uses minimal defensive tests without corrected code. Source verification requires provenance. Translation preserves meaning and register. Reflection preserves lived experience. AI projects test stakeholders, boundaries, accountability, privacy, and accessibility while leaving decisions to the student.
