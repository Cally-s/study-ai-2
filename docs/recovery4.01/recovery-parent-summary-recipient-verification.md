# Parent Summary Recipient Verification

Supported statuses distinguish verified parent, verified guardian, verified authorized adult, reviewed saved contact, student-entered unverified contact, relationship conflict, restricted access, inactive, and unknown. A surname, address, emergency-contact label, former recipient, billing record, IP address, or shared device never proves a relationship.

One recipient is reviewed per sharing action. Multiple parents/guardians require separate selection, confirmation, and potentially different summary versions. Restricted or conflicting relationships block ordinary sharing; no guardian is selected automatically.
