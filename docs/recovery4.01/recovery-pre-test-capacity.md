# Pre-Test Capacity

Pre-test focused capacity contains only confirmed focused minutes between now and the test start/protected stopping time. Protected sleep, buffer, fixed commitments, uncertain windows and unavailable-material periods are excluded. Break/setup values already removed from focused capacity are shown but not subtracted twice.

Statuses distinguish confirmed, limited, tight, none, uncertain, stop reached, test time unknown and outdated. No-capacity behavior protects sleep and offers only verified brief material/question actions or Finish for Tonight. Unknown test time uses conservative restrictions.
