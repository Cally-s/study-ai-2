# Parent Summary Accessibility

The source interface uses semantic headings, fieldsets, labels, native controls, visible focus, status text, a labelled editor, and read-only preview. Controls reflow and stack near 320 CSS pixels and at 200% zoom. Forced colours, high contrast, reduced motion, extra-large text, dyslexia display, reading ruler, RTL, print, simplified, and low-bandwidth contracts are present.

Listen never autoplays. Speech input must require permission and editable review. Language Bridge can review bilingually while sharing only the student-selected language. Accessible PDF depends on the future shared renderer. Browser, screen-reader, speech, PDF, zoom, contrast, language, and representative-user results remain `NOT_RUN` until actually executed.
