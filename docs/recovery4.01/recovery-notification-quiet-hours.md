# Recovery Notification Quiet Hours

The default after opt-in is 9:00 p.m.–7:00 a.m. in an IANA local timezone and supports cross-midnight hours. Protected stopping time additionally blocks ordinary work, deadline, Stretch, and buffer prompts. Only student-selected confirmed tutor/school/supervised session categories may have exact-time exceptions. Suppressed items are revalidated, bundled, or discarded—not flooded next morning. Timezone/DST changes require future-time recalculation and duplicate prevention.
