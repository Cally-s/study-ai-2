# Recovery Plan Accessibility

Minimum and Stretch use separate semantic headings/lists, explicit Optional text, accessible status regions, labelled completion/edit controls, non-drag reorder buttons, error summaries and text dependency/reason explanations.

Contracts cover keyboard, screen reader, 200%/320px reflow, Extra-Large/spacing, light/dark/forced contrast, reduced motion, simplified/dyslexia/reading-ruler displays, Language Bridge/RTL, text-first low bandwidth and print. TTS is presentation-only; STT input must be reviewed before submission. No pointer, hover, timer, media, camera or microphone is required.

Manual browser, AT, zoom, contrast, language, network and participant results remain NOT RUN.
