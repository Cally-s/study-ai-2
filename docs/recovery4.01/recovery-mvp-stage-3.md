# Recovery MVP Stage 3 — Check-Ins and Recalculation

Stage 3 asks what happened using Completed, Partly Completed, Not Started, Blocked or Waiting. It preserves partial work, gives each blocker a resolution action/owner/review point, updates remaining time, removes Stretch first, preserves buffer and proposes a new version for student approval.

Teacher responses may be entered or provisionally extracted but never applied automatically. Progress events are source-grounded and nonpunitive. Existing Check-In, blocker, recalculation and progress services implement the prototype; real offline synchronization is unavailable.
