# Recovery Notification Lock-Screen Privacy

Generic is the default: “StudySpark reminder — A private plan update is ready.” Limited time-only content requires explicit choice. Detailed content remains authenticated in-app. Shared/untrusted devices force Generic, hide recent previews, support Hide details on this device, and require token removal/isolation on logout.

Grades, counts, task/course/person names, messages, tutor requests, parent summaries, emotional/safety/accommodation/disability/medical information, blocker reasons, diagnostics, family/group data, private notes, and sensitive URL parameters are excluded. Deep links contain only opaque paths and require authentication.
