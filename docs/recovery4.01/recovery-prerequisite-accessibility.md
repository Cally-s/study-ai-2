# Recovery Prerequisite Accessibility

The interface uses semantic headings, fieldsets, legends, labels, ordered questions, visible focus, keyboard controls, plain language, math speech text, status text independent of colour, responsive reflow, RTL support, forced-colour support, and reduced-motion handling.

It supports one-question-at-a-time and Show All Questions, Save and Pause, low-bandwidth, simplified layout, reading ruler, and dyslexia-friendly presentation contracts. Browser, screen-reader, zoom, speech, language, and representative-user testing remains required before production release.
