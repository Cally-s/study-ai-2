# Recovery MVP Sequence

Build the smallest reliable human-centred Recovery workflow first. Add automation only after the underlying student, teacher, tutor, privacy, and verification processes have been tested.

The sequence is Stage 1 Intake; Stage 2 Triage and Planning; Stage 3 Check-Ins and Recalculation; Stage 4 Human Support; and Stage 5 Advanced Intelligence. Each stage depends on released earlier stages, independently versioned flags, scope checks and evidence-backed gates. Development may occur behind disabled flags, but availability follows dependencies rather than code presence.

Upgrades preserve cases, tasks, capacity, plans and history through additive records. Rollback disables affected/later flags, blocks new writes, preserves data/audits/messages and leaves earlier stages usable. No stage is declared production-released in this static prototype.
