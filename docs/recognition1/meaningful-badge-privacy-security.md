# Meaningful Badge Privacy and Security

Applications/packages/awards/display plans are private by default; parents receive no automatic access. Packages minimize evidence and exclude conversations, private receipts, safety/counselling/medical/immigration/financial data. Verification snapshots reveal only student-approved fields and use secure Step 59 sharing. Tenant/role/course/student/version controls, secure tokens, prompt/retrieval-injection validation, optimistic concurrency, idempotency, and redacted logs apply. Strict schemas reject usage/popularity/speed/surveillance, risk/global/authorship/honesty scores, sentiment, detectors, rankings, and automatic awards.
