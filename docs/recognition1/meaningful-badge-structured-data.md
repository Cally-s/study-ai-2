# Meaningful Badge Structured Data

Schema `meaningful-badges/1.0` defines versioned tenant-scoped Badge Definition, Criterion, Evidence Requirement, Candidate, Application, Evidence Package, Criterion Evaluation, Human Review, Award, Display Configuration, Verification Snapshot, Correction/Revocation, and Event records. Awards link exact badge/criterion/evidence versions, reviewer, issuer/scope/date, and limitations. Definition changes never rewrite old awards; public state stays separate from private award state.
