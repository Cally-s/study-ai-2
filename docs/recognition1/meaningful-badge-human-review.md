# Meaningful Badge Human Review

Authorized reviewers see only submitted packages and separately authorized evidence. They verify definition/criterion/evidence/policy versions, provenance, reasoning, independence, source status, and limitations; record every criterion status; and provide feedback. Award Recommended is not an award. Only an authorized human with an actual issuer and scope can create an immutable award. AI drafts cannot grade, award, discipline, or infer authorship/honesty.
