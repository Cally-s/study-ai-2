# Accessibility Preview Standard

Step 24 treats browser-state previews as evidence-producing check methods only when actually run. Generic labels and simulations produce NOT_TESTED or UNABLE_TO_TEST, never PASS.

Preview types include Low-Bandwidth, keyboard/focus order, screen-reader-oriented structure, standard display presets, and authorized learner functional settings. Generic presets use no learner. Learner preview requires a current recipient-scoped grant, exposes an eight-field allowlist, is labelled read-only, never impersonates the learner, and cannot edit account settings. Simulations do not prove browser, screen-reader, network or device behavior.
