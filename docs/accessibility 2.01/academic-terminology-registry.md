# Academic Terminology Registry

The versioned `2026.1` local registry contains development-only Biology entries for Photosynthesis, Light energy, Chemical energy and Chlorophyll with Simplified Chinese equivalents, English/Chinese definitions, subject, source and review status.

The intended priority is organization-approved glossary, human-reviewed translation, teacher-reviewed translation, approved domain dictionary, validated automatic translation, then honest untranslated fallback. This prototype implements only organization-glossary entries and untranslated fallback. It does not invent missing equivalents.

Term senses must be scoped by subject/course/definition so mathematical, programming and ordinary meanings of “function” are not merged. Rejected/outdated entries are not current. English is equally prominent, translations are associated in a semantic definition list, and passive glossary entries do not create unnecessary Tab stops.
# Step 13 extension

The registry now includes subject-scoped senses, definitions, examples, relations, misconceptions/corrections, pronunciation metadata and aliases for approved vocabulary fixtures. Function demonstrates separate Mathematics and Computer Science meanings. This remains local fixture data, not a production terminology database.
# Step 14 response use

Multilingual responses reuse approved registry/glossary entries for English-term preservation and keyword cards. Canadian abbreviation fixtures are separate review-pending scoped information and are not approved academic translations or current policy records.
