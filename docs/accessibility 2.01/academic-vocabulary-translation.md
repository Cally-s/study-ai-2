# Academic Vocabulary Translation

Translations reference a canonical term/version, target language, context, ambiguity, discouraged alternatives, example, pronunciation, reviewer, and immutable translation version. Machine and student drafts require authorized human review; policy, integrity, safety, privacy, and evidence terms require context-aware reviewers. Code identifiers, URLs, DOIs, mathematical symbols, quotations, titles, and proper names remain original where necessary. No translation is treated as universally correct across disciplines.
