# AI Response Presentation Precedence

Canonical precedence is response, task/lesson, conversation, account AccessibilityPreferences, device, operating system, then default. Only explicit confirmed Save as Default updates the account record.

Precedence is response override, conversation override, lesson/task override, account default, then Standard Academic/English defaults. Response scope is default. Conversation/lesson require explicit selection; account default requires explicit action and confirmation. Current implementation is memory-only and durable account sync is unavailable.
