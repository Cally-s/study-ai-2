# Alternative Text Authoring Standard

Step 24 separates automated presence checks from human quality review. Source-image changes invalidate alt approvals and long-description review.

Informative images require concise contextual alternative text. Empty alt is valid only with an explicit decorative decision and human review. Complex images, charts, graphs and diagrams require long descriptions and, where appropriate, data alternatives that preserve labels, units, relationships, trends and conclusions. Filename/generic text is flagged. AI suggestions remain labelled drafts tied to the exact image hash/version and never publish automatically.
