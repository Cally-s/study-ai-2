# Nodes and Edges

Nodes document users, controls, rules, models, sources, validation, review, response, feedback, logs, retention, maintenance, and shutdown. Typed edges include success, invalid input, privacy/safety/policy blocks, no/conflicting source, validation failure, low confidence, reviewer unavailable, refusal, escalation, fallback, outage, offline, revision, retest, and shutdown. Show more than the happy path.
