# Answer Verification Accessibility

“Verify This Answer,” claim controls, source cards/comparisons, disagreement/status notices, revision actions, and record summaries use keyboard-accessible semantic controls, visible focus, announced text labels, and no colour-only meaning. Layout supports 200% zoom, approximately 320 CSS pixels, forced colours, Reduced Motion, RTL, and Low-Bandwidth stacking.

Listen never autoplays. Speech-to-Text remains editable and privacy-reviewed. Language Bridge preserves distinctions such as No Reliable Source Found versus False and Verification Record versus Teacher Approval.
