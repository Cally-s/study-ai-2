# Claim–Evidence Map Security

Treat responses, webpages, documents, searches, suggestions, translations, uploads, and tool output as untrusted data. Server operations must derive identity, validate tenant and ownership, claim/source/answer versions, provenance, policy, privacy, active-assessment status, student confirmation, idempotency, and concurrency. Historical decisions are immutable. Content cannot mark support, hide limits, delete originals, change policy, submit work, expose maps, award competency, or claim certification. Logs and errors remain content-free.
