# Answer Verification Records

Versioned records preserve original answer/version, verification date/workflow, claims/types/evidence needs/statuses, sources/types/dates/authority/originality/relevance, claim–source relationships, disagreement, calculation/code checks, explanations, revisions, uncertainty, human-review recommendation, policy, and privacy.

Reverification creates a new version when sources become outdated/superseded/corrected/retracted, current information expires, policy/answer/claim changes, or new evidence appears. History remains; eligible records support deletion without erasing the conversation automatically.
