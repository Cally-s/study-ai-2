# Claim–Evidence Map Accessibility

The structured-card alternative supports keyboard and screen-reader use without dragging. It provides semantic headings, skip links, visible focus, status text independent of colour, 200% zoom and approximately 320 CSS-pixel reflow, forced colours, reduced motion, RTL, text-only, Low-Bandwidth, and one-claim navigation. Listen never autoplays. Speech-to-Text remains editable and never auto-submits. Language Bridge preserves Claim, Evidence, Source, unsupported/false, association/causation, and percentage-point/percent distinctions.
