# Citation and Quotation Verification

Citation checks cover existence, author, title, date, publisher, identifier, relevance, exact support, and correction/retraction/supersession. A real citation can still fail to support a claim; an unlocated citation is not automatically labelled invented.

Quotation checks use original wording, attribution, page/timestamp, date, context, omissions, and quotation marks. Never invent a replacement; remove marks, use a verified quotation, accurately paraphrase, or leave unresolved.
