# Human Agency Accessibility

The lesson uses semantic headings, fieldsets, keyboard controls, visible focus, an accessible comparison table with row/column headers, and narrow-screen comparison cards. It supports 200% zoom, approximately 320 CSS pixels, forced colours, high contrast, Reduced Motion, RTL, bilingual stacking, text-only and Low-Bandwidth presentation. Text-to-Speech never autoplays; Speech-to-Text never auto-submits and requires transcript review.
