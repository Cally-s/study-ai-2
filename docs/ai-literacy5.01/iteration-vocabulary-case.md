# Vocabulary Iteration Case

Prototype 1 preserves standard terms but loses bilingual terms, omits a screen-reader source label, and lacks outage fallback. Linked findings and hypotheses produce terminology validation, accessible labels and static fallback in Prototype 2. Original/regression/accessibility/fairness/outage tests show partial tested-scope improvement; synthetic feedback retains fallback. Untested languages, human-review dependency and synthetic-only testing remain visible.
