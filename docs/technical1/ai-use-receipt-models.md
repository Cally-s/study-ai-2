# AI Use Receipt Models

> Step 66 integration: the decision flow creates only a private `AIUseReceiptOffer`. A Step 65 receipt/version is created later only through the student’s explicit Save action and still requires review before approval or sharing.

`AIUseReceipt` is the student-owned stable identity for a session and assignment. Immutable versions describe purpose, AI contribution, student contribution, revisions, and disclosure text. `sourcesVerified` is server controlled. Student approval requires an explicit confirmation and freezes that version. Source, evidence, and share links are normalized so receipt history remains attributable without duplicating source truth.
