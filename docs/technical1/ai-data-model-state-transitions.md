# AI Data Model State Transitions

Published definitions and policies, submitted lesson attempts and artifacts, approved receipts, reviewed records, response turns, and evidence-ledger entries are immutable. Corrections create a successor version or an explicit superseding/invalidation record.

Profiles and in-progress lesson/project pointers allow optimistic updates using `expectedRowVersion`. Policy publication moves the identity pointer to the published version. Receipt approval moves the receipt state only after student confirmation. Offline claims remain pending until online checks and authorized review. No transition silently turns pending data into completion, evidence, recognition, a grade, a safety finding, or a disciplinary outcome.
