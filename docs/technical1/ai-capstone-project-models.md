# AI Capstone Project Models

`AICapstoneProject` stores the community need, intended users, problem statement, AI justification, non-AI alternative, review states, deployment state, reflection, and lifecycle. Membership, stakeholders, system-card versions, prototype versions, human reviews, tests, and feedback are separate records. The server owns current-version pointers. Default deployment is `DO_NOT_DEPLOY`; creating a prototype never authorizes deployment.
