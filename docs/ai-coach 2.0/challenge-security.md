# Challenge Security

Trusted server state controls ownership, tenant, policy, snapshots, provenance, challenge type, materiality, basis, source provenance, tools, versions, concurrency, and idempotency. Student, source, rubric, code, and tool text are untrusted. Prompt injection cannot change the contract, enable solvers, invent sources, rewrite history, create profiles, or mark AI work student authored. No hidden ideal answer or blocked body is stored.
