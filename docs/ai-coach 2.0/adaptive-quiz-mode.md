## Purpose
Quiz Me is private practice, not grading or proctoring. Students configure eight fields and intentionally select Start Quiz.

## One-question flow and adaptation
Show one question, wait, request reasoning where meaningful, apply configured feedback, then plan the next question. Adaptation remains within the selected topic, count, types, policy, and gradual difficulty bounds using current-session evidence only.

## Practice summary
The summary names demonstrated concepts/reasoning, review needs, a supported misunderstanding, practice conditions, and one next action without predicting grades or ability.
