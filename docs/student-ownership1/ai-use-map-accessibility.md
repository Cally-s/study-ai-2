# AI Use Map Accessibility

Categories use exact symbols plus visible labels and accessible names; assignment status and conditions are text, never colour-only. Semantic regions/lists, keyboard focus, 44-pixel targets, screen-reader announcements, controlled TTS, review-before-submit STT, 200%/320px reflow, high contrast, forced colours, Reduced Motion, print/text-only, bilingual explanations, RTL, mobile, and Low-Bandwidth views preserve category-versus-policy meaning. Interface and approved accommodation translation remain distinct from academic content generation.
