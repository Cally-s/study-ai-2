# AI Use Receipt Prompts

Only assignment-relevant prompts that materially affected assistance are considered. Shareable receipts prefer concise summaries; exact excerpts are optional and require explicit selection. Duplicates, greetings, navigation, retries, raw files, safety disclosures, accessibility commands, identifiers, passwords, other people’s information, prompts, and hidden reasoning are excluded. Students can include, remove, restore, summarize, edit accurately, or redact. The immutable private event reference remains; full transcripts are never included by default.
