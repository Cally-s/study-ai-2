# AI Use Map Privacy

Map views, questions about restricted use, and planned-use records remain private by default and do not create teacher alerts, disciplinary records, honesty/misconduct/ability/dependence scores, or AI-use receipts. Events exclude prompts, drafts, teacher-message text, safety content, accessibility details, and internal traces. Safety support bypasses the map. Accessibility usage is not academic AI contribution. Sharing requires an explicit reviewed student workflow.
