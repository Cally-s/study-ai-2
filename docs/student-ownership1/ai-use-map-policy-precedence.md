# AI Use Map Policy Precedence

Resolution order is immediate safety; law/mandatory requirements; accessibility guarantees/accommodations; active assessment or competition; school/organization; course; assignment; authenticated teacher clarification; unverified student report; then general guidance. Lower permission cannot override a higher restriction. Accessibility presentation functions remain available. Conflicts fail closed for task-specific tools, show a concise sourced explanation, preserve drafts/history, and offer clarification without accusation.
