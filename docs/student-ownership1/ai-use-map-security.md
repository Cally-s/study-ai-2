# AI Use Map Security

The server derives identity/tenant/assignment, resolves verified versioned policy and precedence, enforces integrity boundaries and conditions, and authorizes every tool call against the same immutable resolution. Hidden buttons are not security. Prompt/retrieved/student content cannot alter trusted policy; student reports stay unverified. Stale map/policy versions fail closed. Tenant isolation, idempotency, source watermarks, row versions, immutable history, and account-isolated offline caches prevent bypass and duplication.
