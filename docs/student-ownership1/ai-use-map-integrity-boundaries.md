# AI Use Map Integrity Boundaries

Verified structured policy cannot authorize false evidence, false attendance/absence, invented real sources or quotations, deceptive concealment, impersonation, falsified contribution, invented personal experience, or unauthorized active-assessment completion. Clearly labelled fictional sources, synthetic practice data, eligible model answers, and teacher-assigned comparisons may be valid instructional exceptions only through structured verified fields. Free text or student claims cannot establish an exception.
