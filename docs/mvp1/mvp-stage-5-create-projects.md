# MVP Stage 5: Create-Level Projects

Stage 5 depends on Stages 1–4 and adds the Community Project pathway, problem scoping/non-AI alternatives, Student System Cards, accessible architecture design, data-responsibility review, fairness testing, project accessibility review, immutable prototype versions, stakeholder feedback, and ethical/social reflection.

It reuses Stage 4 human review and Step 65 capstone models. Student work uses synthetic/de-identified data, secret scanning, provenance, limitations, failure paths, and explicit deployment decisions. **Do Not Deploy** is valid; public deployment is never required for completion, recognition, or evidence.

Release gate includes accessible diagram alternatives, failed-test recording, human review, safe data, security, prior regression, production build, and no Critical issue. Current result: **Blocked by earlier stages and production infrastructure**.
