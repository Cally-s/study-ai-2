# MVP Stage 1: Coaching and Integrity Foundation

The intended vertical journey connects AI Literacy Lab entry; six Understand modules using Learn–Observe–Practise–Explain–Reflect; a persistent Stage 1 mode selector; server final-answer lock; **Your Current Thinking** attempt entry; assignment/task context; canonical versioned policy; Privacy Check; and integrity redirection.

Existing prototype modules cover What AI Is and Is Not, human thinking/responsibility, unsupported output, privacy, original work, and policy awareness. Attempts accept text, reviewed speech, equations, diagrams, code, sources, outlines, and uncertainty without word/timing/style/AI detection. Policy unknown is guided/locked; AI Not Allowed preserves access/general guidance; active tests redirect to after-test support. Opening a lesson creates neither completion nor competency.

Release gate requires every listed workflow, authentication/tenant enforcement, keyboard/screen-reader/200% access, secret blocking, no hidden answers, automated tests, production build, and no Critical issue.
