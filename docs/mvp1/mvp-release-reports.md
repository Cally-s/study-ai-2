# MVP Release Report Template

Create one immutable report per stage and release attempt.

## Stage

- Exact stage title and manifest version
- Release channel
- Gate result and dependency results

## Features completed

- End-to-end released features only

## Features deferred or in internal testing

- Feature IDs and limitation references

## Delivery evidence

- Files changed
- Migrations actually run
- Tests actually run and failures
- Failures fixed
- Production build reference
- Security/privacy/accessibility evidence

## Remaining issues

- Critical issues
- High issues
- Known limitations

## Rollback

- Flag changes
- Work/history preservation
- Migration rollback or forward-fix plan

Never mark a stage Released from UI presence, hard-coded output, client-only controls, or unrun checks.
