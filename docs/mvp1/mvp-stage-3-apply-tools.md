# MVP Stage 3: Apply-Level Tools

Stage 3 depends on Stages 1–2 and joins Prompt Coach/version comparison, Answer Verification, Claim–Evidence Map, Source Comparison, private versioned AI Use Receipts, editable disclosure drafts, student-owned draft feedback, and Independent Retry.

These workflows reuse the canonical prompt/privacy, source/claim, evidence, receipt, response, policy, and decision services. Receipts and disclosures require student review/action and are never automatic. Draft feedback requires a student artifact; retry evidence requires independent transfer and accepts accessibility support. Prompt/receipt counts do not demonstrate competency.

Release gate includes end-to-end persistence, source integrity, security, accessibility-supported retry, prior regression, production build, and no Critical issue. Current result: **Blocked by earlier stages and production infrastructure**.
