# Blocked Acceptance Status

Unknown acceptance moves the task to Ask First, removes substantial work from READY_NOW, preserves partial progress, creates/reuses a reviewed accepted-work draft, shows another confirmed task, sets review, and recalculates deadline risk.

Accepted/conditional/replaced/no-longer-required statuses require teacher/official authority and preserve conditions/history. AI, tutors, drafts, messages, uploads, or student preference cannot create official acceptance. Uncertain substantial work stays unscheduled.
