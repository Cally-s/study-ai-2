# Academic Integrity Privacy

Store minimum context/policy/version/decision/reason/support/checkpoint metadata—not full prompts, assignments, drafts, active-test content, medical/disability/emotional data, messages or raw speech by default. Public, parent, teacher, tutor and ordinary-staff access is empty unless a separately authorized human-review process applies. Review evidence has disclosed retention/access controls. Analytics/logs exclude restricted content. Integrity data never affects grades, automatic discipline, Help Credits, service hours, rankings, profiles or advertising.
