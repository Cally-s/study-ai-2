# Recovery Concept Bridge Plan

A bridge is a five-to-twenty-minute sequence: short explanation, similar worked example, guided practice, and independent check. It must fit confirmed focused capacity, preserve breaks, and never use protected buffer or silently add an entire unit.

The same active prerequisite is reused across related tasks rather than duplicated. Creating or changing a bridge invalidates feasibility and priority outputs; it does not complete the task or automatically change its priority.

Step 12 expands this bridge into an interactive five-stage repair attempt while retaining the same minimum-concept, capacity, break, buffer and deduplication invariants.
