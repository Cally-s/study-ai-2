# Blocked Active-Plan Rules

On blocking, preserve completion/partial products; remove the academic action from READY_NOW, active Minimum, next action, and Start-10; retain the work in Blocked and Waiting or Ask First; add only the resolution action when it fits; show another ready task; and set review.

The resolution action—not the blocked assignment—is the active Minimum step. Keep Unscheduled and Finish are valid. Resolution evidence triggers reactivation review; it never marks the assignment complete. No automatic rollover or protected buffer use occurs.
