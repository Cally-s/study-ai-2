# Blocker Routing

Reasons map deterministically to conceptual, instructional, teacher-decision, material, technical, collaboration, accessibility/accommodation, requirement/acceptance, emotional/personal, safety, or unknown categories. Students see their chosen reason, not diagnostic labels.

Routing prioritizes immediate safety, existing safe settings/materials, current-concept help, narrow prerequisite, source clarification, reviewed communication, technical/accessibility/human support, another ready action, and Finish. Every action has a verb/object, done condition, owner, dependencies/materials, communication status, privacy level, and review point. No opaque score selects it.
