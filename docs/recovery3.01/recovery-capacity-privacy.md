# Recovery Capacity Privacy

Daily time, school/work/tutor/activity/family/medical/transport/sleep schedules, concentration/break preferences, variability, support overrides and notes are private student planning data. Owner views use generic commitment labels and omit medical/family/employer details, tokens, credentials and diagnosis data.

The public serializer is empty. Capacity is excluded from teacher/tutor/parent/guardian dashboards, profiles, notifications, grades, matching, service hours, Help Credits and safety/fraud/integrity/advertising scores. Ordinary analytics contains reviewed event name/time only, never exact schedules or supports.

Later sharing needs defined recipient/fields, exact editable preview and confirmation. AI receives only confirmed minutes, generic unavailable blocks and allowlisted functional preferences—not diagnoses or private details. Production needs authenticated encrypted persistence, deletion/export/shared-device controls and provider review.
