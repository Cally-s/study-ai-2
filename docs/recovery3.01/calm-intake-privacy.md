# Calm Intake Privacy

Primary concern, unknown states, due context, available time, custom concern, later stop time and communication context are private student data. They are absent from public/teacher/tutor/parent/guardian views and never affect grades, matching, service hours, Help Credits, safety/fraud/integrity scoring or advertising.

Ordinary analytics contains only allowlisted lifecycle event and time—never answers, titles, courses, durations or text. AI-provider input, if later approved, must minimize to confirmed academic context and exclude diagnoses, medical/accommodation records, unrelated history, parent data, safety/fraud data and private tutor notes.

Local retention is prototype-only. Production requires authenticated ownership, organization isolation, encryption where appropriate, export/deletion/retention rules, account-switch cleanup and reviewed aggregate thresholds.
