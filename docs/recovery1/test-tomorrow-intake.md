# Test Tomorrow Intake

The urgent sequence begins with authorized subject/course, exact test date/time, realistic preparation time, fixed stopping time, important topics, highest-value topic, optional resources and active-assessment confirmation. Exact timing is interpreted using a trusted current time and preserved timezone.

The fixed-stop explanation protects sleep and essential responsibilities. The router never expands that time to fit more work. Resources are optional. Unknown topics trigger checking course/teacher material rather than invented content.

A passed time returns an honest review/next-assessment message. A test beyond 36 hours remains supported with its exact date. An active assessment must not receive unauthorized answers. No grade, deadline or completion outcome is promised.
