# Blocked Workflow Accessibility

The semantic view uses heading, fieldset/legend, labelled native radios/buttons, visible focus, concise one-question routing, and no drag/hover/mouse/audio requirement. It supports keyboard/screen reader, 200%/320px, extra-large, contrast/forced colours, reduced motion, dyslexia display, reading ruler, RTL, text-only, and low bandwidth.

Listen never autoplays; speech requires permission/editable review; Language Bridge preserves reason/action/status. Browser, AT, speech, language, display, cognitive and representative-user results remain `NOT_RUN`.
