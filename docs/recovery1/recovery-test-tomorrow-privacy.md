# Test Tomorrow Privacy

Test details, topics, understanding/confusion, diagnostic answers, repairs, viewed examples, recall, mistakes, permitted materials, stop time, duration, questions/help and topics not covered are student-private.

Public/teacher/tutor/parent/guardian serializers return nothing. Sharing requires exact preview, recipient, fields, editing and confirmation. Notifications and analytics exclude subject/topic/test/answer/mistake/time content. AI receives only minimal confirmed academic context, never diagnoses, family/employer/guardian details, accommodations, safety/fraud data, hidden keys or unrelated courses.
