# Recovery Text-to-Speech

Listen applies to all recovery instructions, questions, explanations, plans, actions, specialized modes, messages/summaries, check-ins, recalculation, blockers, support, recognition, metrics, notifications, privacy, and vocabulary. Controls include Play, Pause, Stop, skip, speed (0.75–2x), voice, language, sentence highlighting, supported word highlighting, and Close. Visible source text remains; no autoplay. Math uses understandable speech while preserving visible notation. Bilingual sequencing is stable and voice-appropriate. Content/voice history stays private.
