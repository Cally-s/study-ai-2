# Recovery Verification Privacy

Facts, excerpts, corrections, confidence, estimates, weights, policies, drafts, conflicts, proposed negotiation, actions, and history are private student recovery data. Public, teacher, tutor, parent, and guardian serializers return no verification review. Data never affects grades, matching, service hours, Help Credits, safety, fraud, integrity, discipline, or advertising.

Safe analytics contain an allowlisted event name and timestamp only. Later sharing requires a named recipient, exact fact/question preview, student edits, and explicit confirmation. AI receives only minimal validated field context/source excerpt and cannot establish authority, change facts, send, or promote assumptions. Medical, family, employer, diagnosis, accommodation, guardian, safety/fraud, hidden-answer, credential, and unrelated-course content is excluded.
