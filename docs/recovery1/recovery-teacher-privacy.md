# Teacher Recovery Privacy

Teacher sharing is verified and course specific. A selected snapshot may contain tasks, confirmed deadlines, task statuses, decision questions, proposals, progress facts, and functional requests. Other courses, check-in reasons, capacity/family/medical/emotional/safety data, private conversations, tutor/parent records, integrity records, notifications, and full accessibility profiles are excluded by default.

Sending a Step 22 message shares only the reviewed message and creates no plan grant. Access expires and is visible in Access History; unrelated teachers are denied.
