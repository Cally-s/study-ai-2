# Recovery Workload Entry Methods

Step 5 offers seven controlled methods: manual entry, pasted task list, pasted course-page text, assignment-sheet upload, calendar-screenshot upload, approved school-system import and an own-words description. Every non-manual result is a private draft; nothing enters the Step 4 inventory until required fields are reviewed and confirmed or explicitly marked unknown/not applicable.

Manual entry reuses Step 4. Paste-list, course-page and own-words methods use the local deterministic parser. Secure uploads, OCR/vision and school connectors are honestly unavailable because scanning, private object storage, processor authorization and OAuth services are absent. Their cards state why instead of offering false working controls.

Native controls, labelled text areas, semantic candidate regions, text confidence/confirmation states, keyboard actions, 320px reflow, forced colours, reduced motion and RTL contracts are included. Low-bandwidth/offline users can start with manual or paste methods; no cloud work begins on reconnection automatically. Sources and candidates are private, analytics-redacted and deletable. Browser/AT/network testing remains pending.
