# Recovery Work Inventory Privacy

The inventory is private student planning data: titles, manual course names, dates, statuses, estimates, grade weights, late-work uncertainty, dependencies, instruction confusion, materials, teacher drafts, applications, meetings and notes.

It is excluded from public profiles, teacher/tutor/parent/guardian dashboards, class lists, directories, service hours, Help Credits, badges and notification previews. It does not affect grades, matching, safety, fraud or academic-integrity scoring. Teachers may separately see official course records, but never automatically receive the recovery copy or student planning fields.

The public serializer is empty. Owner, summary, suggestion, history, question, source-update, error and offline views are allowlisted. Ordinary analytics contain only reviewed aggregate event name and time—not titles, courses, dates, weights, estimates, materials, questions, applications, meetings or notes.

Local device drafts are user/session keyed in the executable prototype. Production must add authenticated encrypted storage, organization/course/source authorization, retention/deletion/export policies, shared-device cleanup and durable sync before claiming server privacy. Later sharing requires a defined recipient, exact selected items/fields, preview, editing and explicit confirmation.
