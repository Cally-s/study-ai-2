# Recovery Task Decomposition Privacy

Action lists, progress, actual time, private notes, draft details and source excerpts are student-private. Teacher, tutor, parent, guardian and public serializers return no decomposition data. Later sharing requires scoped consent.

Ordinary analytics contain event name and time only. AI input is limited to relevant confirmed requirements and progress. Saving or accepting never submits, messages, changes grades, ranks tutors, records service hours or affects safety/fraud/integrity scores.
