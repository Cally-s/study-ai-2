# Test Tomorrow Accessibility

The source contract uses semantic headings/lists, three short intake groups, labelled topic/diagnostic/example/recall/material/stop sections, native controls, alerts/status and a Step 16 one-action option. Overwhelmed Mode shows one question/topic/block at a time.

Styles cover visible focus, 200%/320px reflow, forced colours, reduced motion, Simplified Layout, dyslexia spacing, reading ruler, RTL, Low-Bandwidth text and print. Mathematics, TTS, speech review and Language Bridge must preserve exact dates/times, notation, verification and stop rules. Manual browser/AT verification remains required.
