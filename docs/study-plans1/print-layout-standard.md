# Print Layout Standard

Letter and A4 use 0.65-inch safe margins, black selectable text on white, system/monospace typography, semantic headers, browser page footer notice and no ink-heavy decoration. Headings avoid breaks; days, questions, task labels, vocabulary definitions and note areas use break-inside protection. Questions retain answer space. Checkboxes use visible Unicode plus adjacent labels. Tables require headers; images/graphs require text descriptions; math/code remain text; RTL uses document direction. Actual pagination/driver verification is pending.
