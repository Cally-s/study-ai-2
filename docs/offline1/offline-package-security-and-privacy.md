# Offline Package Security and Privacy

Creator/publication/download authority are server contracts the static client cannot prove. Controlled rights are required; expired licences, copied link-only content, restricted assessments and private fields are rejected. Packages exclude tokens, keys, contact/guardian/medical/safety/integrity/private-chat data. Shared-device warnings are required. No usage affects profiles, matching, grades, safety, fraud, integrity, service hours, Help Credits or advertising. Scanning, expiring URLs, cryptographic hashes and durable owner isolation are unavailable.
