# Offline Package Content Standard

Controlled components cover summaries, vocabulary, examples, practice/questions keys, formulas, checklists, reflections, plans, authorized transcripts, audio text, descriptions, diagrams, answer pages, bilingual content and schedules. Authorized sources and controlled rights are mandatory. AcademicContentContract invariants and English terms must survive formatting. Questions require stable IDs/validation; audio requires visible text; active assessments, restricted banks and private content are blocked.
