# Compressed Illustrations

Assets provide low-bandwidth, standard, and optional high-resolution variants with reserved dimensions, lazy/explicit loading, byte sizes, exact academic labels, alt text, long description, text-only alternative, grayscale print, high contrast, language, licence, and immutable version. Compression cannot make labels or essential meaning unreadable. Hidden answers and unauthorized student images are excluded from pixels and metadata. Asset bytes count toward the displayed package size.
