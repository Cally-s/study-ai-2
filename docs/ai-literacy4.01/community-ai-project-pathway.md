# Community AI Project Pathway

> Step 28 completion now requires the canonical Ethical and Social Review Gate. Academic completion permits private, report-only, non-AI, no-deployment, pause, and stop outcomes.

## Purpose
Guide students from a verified need to a responsible AI, hybrid, non-AI, or no-build outcome.

## Workflow
Identify a Need → Speak with Stakeholders → Determine Whether AI Is Appropriate → Define the Problem → Design the Workflow → Build a Prototype → Test Accuracy and Safety → Evaluate Fairness and Accessibility → Collect Feedback → Revise → Reflect on Impact.

Students may return to earlier stages as evidence changes. This in-memory learning prototype does not contact stakeholders, deploy, certify, or award competency.

## Step 22 gate

Problem Scoping Studio requires student-confirmed evidence, consultation status, current state, alternatives, minimum information, risks, error impacts, human accountability, and boundaries before workflow design or prototyping.

## Step 23 system card

Every AI, hybrid, non-AI, human-led, existing-tool, feasibility, or no-build project maintains a versioned AI System Card. Material project changes mark it for student review.

## Step 24 architecture gate

Step 21 now treats workflow and architecture as one connected design stage. Functional AI/hybrid building requires a confirmed current architecture; non-AI and no-build designs retain equivalent records.

## Step 25 data gate

Every dataset version and purpose requires a current Data Plan before collection, upload, import, connection, embedding, external processing, functional use, sharing, or export. Confidential records remain prohibited.

## Step 26 fairness gate

A current scenario-based Fairness Evaluation is required before broad suitability claims, stakeholder sharing beyond an authorized limited test, public-safe deployment-ready export, deployment recommendation, consequential use, or project completion.

## Step 27 iteration gate

Project completion/final presentation/public-safe export/pilot review/tested-and-revised/broader-use/Create-review claims require a confirmed current Iteration Record with honest evidence, oversight, consequences and visible limitations.
