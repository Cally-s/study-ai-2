# Multilingual School Vocabulary Assistant

This synthetic controlled case follows all eleven stages. Its hybrid decision keeps curated definitions authoritative and uses AI only for labelled, reviewable examples, with static fallback. Twelve tests cover ambiguity, privacy, policy, injection, multilingual, RTL, keyboard, bandwidth, and changed meaning. Revisions correct translation, reorder examples, clarify audio, add a private glossary, and preserve fallback. Human review remains required and public deployment requires school review.
