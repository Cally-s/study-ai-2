# Data Inventory

Prefer synthetic, fictional, public, open-licensed, curated, or authorized de-identified data. Record purpose, source, permission, sensitivity, access, sharing, accuracy, currentness, retention, deletion, and minimization. Personal and sensitive data require authorized review.

## Architecture flows

Every transferred item links classification and permission to source/destination, minimization, external crossing, logging, retention, deletion, access, notice, and failure behaviour.

## Step 25 canonical planning

Data Responsibility Studio extends the existing inventory with purpose-specific questions, permission, personal/re-identification risk, coverage/quality, lineage, least-privilege access, complete deletion, freshness, and Dataset Cards rather than creating a duplicate inventory.
