# Printable Lessons

Immutable print snapshots preserve headings, objectives, instructions, academic terms, sources/citations, warnings, answer spaces, diagram/text alternatives, transcript references, policy boundaries, language, and version. They exclude hidden answers and interactive-only metadata. Restricted content/copyright remain enforced; student-specific output is not publicly cached. Printing is not submission or AI-use evidence.
# Step 64 source worksheet

Offline print packages can include source-checking worksheets, but they must distinguish preliminary notes from verified outcomes and show **Verification pending internet access**. Print snapshots include package/activity/policy versions and cannot contain hidden answers, teacher rubrics, or final source outcomes.
