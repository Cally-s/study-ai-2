# Language Bridge Validation Standard

Validation runs against the original source and reused AcademicContentContract. It checks supported mode/language/level, source ancestry, required English-term visibility, required bridge content by mode, and Step 10 exact preservation for terms, formulas/equations, values and units. Structured semantic blocks require stable IDs and source element references.

Assessment and high-stakes checks run before display. Active assessments are blocked unless source policy explicitly permits support; high-stakes translated content requires real human-review metadata and official English remains authoritative.

Back translation, word count, readability, embeddings and model self-claims are not proof. No independent semantic, contradiction, qualification, terminology-sense or factual-equivalence provider exists, so general full translation is unavailable. The deterministic approved-fixture path has no corrective model retry. Failure preserves English and may expose an approved glossary/keyword fallback; it never displays an unvalidated partial translation.
