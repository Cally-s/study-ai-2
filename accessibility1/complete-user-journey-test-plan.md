# Complete User Journey Test Plan

## Purpose and layers

Step 26 evaluates 25 meaningful outcomes using four distinct layers: deterministic automation, automated accessibility scans, manual assistive-technology testing, and representative-user testing. Automation never substitutes for the latter two.

## Coverage

The planned matrix includes Chrome, Firefox, Safari and Edge; Windows, macOS, iOS, Android and ChromeOS; desktop/laptop/tablet/phone; NVDA, JAWS, VoiceOver, TalkBack, Narrator, voice input, magnification and switch control; English, Mandarin, French and Arabic RTL; four explanation levels; stable, weak, slow, unstable, offline, reconnecting, storage-full and provider-unavailable conditions.

Every journey tests privacy, applicable failure/recovery, no automatic actions and synthetic data. Release requires all required layers, no unresolved Blocker/Critical issue, no data loss/privacy leak, and complete evidence. This repository has no browser E2E lab or human participants, so release is not recommended.
