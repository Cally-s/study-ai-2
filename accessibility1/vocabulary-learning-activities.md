# Vocabulary Learning Activities

Validated saved snapshots can create on-request Flashcards, Matching, Pronunciation Practice, Vocabulary Quiz and Bilingual Review Sheet data. The student explicitly selects entries. Every artifact is labelled **Personal vocabulary practice**, private, formative and without official-grade effect; English terms remain in activity data.

No activity starts automatically on save. Matching data does not require dragging, and deterministic stored fields avoid invented answers/distractors. The static prototype exposes activity data APIs only; complete interactive players, scheduling, files/PDF/DOCX exports, scoring UI, correction invalidation and browser accessibility journeys are NOT_AVAILABLE/PENDING.

Active restricted materials cannot enter lookup and therefore cannot enter activities. Results are not used for ability labels, grading, matching, pronunciation scoring or consequential decisions.
