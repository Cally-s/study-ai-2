# Personal Vocabulary Glossary

Saving is optional and occurs only after the student selects the card’s Save action. Session-private prototype rows are scoped by the current simulated user ID or private device key. Duplicate sense/language saves are idempotent; different senses remain distinct.

Snapshots retain English term, optional translation/language, plain and academic definitions, subject, example, registry version and source ancestry. List views support local search and subject/language filtering and omit owner keys and private notes. Removal is soft for the session.

The model reserves collections, tags, favourites and private-note fields, but editing/organization/export, durable account synchronization, registry-update comparison and offline persistence are NOT_AVAILABLE. The glossary is not serialized to public profiles, tutors, guardians, organizations, matching, grades, safety/fraud/integrity, service, Help Credits or advertising.
