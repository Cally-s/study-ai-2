# Human Accessibility Review Standard

Human tasks cover full keyboard journeys, screen-reader spot checks, alt-text quality, caption and transcript accuracy, plain-language meaning, translation, cognitive accessibility, academic equivalence, Low-Bandwidth experience, print output, RTL, disabled-student review and organization review. Automation never completes them. Sign-off requires a trusted reviewer, decision, evidence, exact version/hash, time, expiration where applicable, and preserved history. Source changes or expiry require new review.
