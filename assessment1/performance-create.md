# Create Assessment

Students define a meaningful problem without exposing private experiences, decide whether AI is appropriate, consider non-AI alternatives, design a workflow/data plan, build a safe flexible prototype, test accuracy, fairness and accessibility, analyze error harm, design oversight, respond to feedback, document limitations and conditions not to use, and reflect on social consequences. A justified **Do not deploy** decision is valid evidence. Public deployment, real confidential data, and high-risk processing are never required.
