# Recovery Repair Content Standard

Explanations name the academic concept, connect it to the current task, preserve terminology and state one core rule in roughly 75–200 words or equivalent notation. Simpler variants retain the original and the same expectation.

Worked examples are reviewed, course-level appropriate, distinct from graded work, stepwise and reasoned. Guided practice requires a meaningful response and offers, in order, concept reminder, first-step prompt, partial structure, specific hint and an explicitly requested full explanation. Independent checks use new equivalent items, initially hide hints and distinguish independent, corrected and supported completion.

Source priority is teacher-approved content, verified StudySpark content, verified curriculum content, authorized textbook-style content, then independently validated structured AI output. The prototype implements only the verified synthetic bank; AI generation fails safely.

Validation covers concept/method, level, answers, hint order, notation, versions, duration, active-assessment separation and `PRACTICE` integrity classification. Student-facing serializers exclude answer keys.
## Prerequisite-help content

Every explanation/example/check retains concept/course/method/source/content/answer/integrity versions. Worked/guided/independent items differ from graded work and are independently validated before use.
