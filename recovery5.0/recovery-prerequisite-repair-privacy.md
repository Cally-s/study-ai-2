# Prerequisite Repair Privacy

Concepts, viewed content, answers, hint use, corrections, readiness decisions, self-assessment, drafts, disagreements and history are private student data. Public, teacher, tutor, parent and guardian serializers return nothing automatically.

Tutor/teacher actions are unsent drafts. Later sharing requires a named recipient, exact field preview, student editing and explicit confirmation. Full answers, diagnostics, other courses, priority/capacity data, diagnoses and private notes remain excluded.

Allow-listed analytics contain only an event name and time. They exclude content, answers, concept-linked identity, decisions, hint text, notes and draft text. Repair data cannot affect grades, tutor ranking, service hours, Help Credits, safety, fraud, integrity or advertising.

AI inputs, if later enabled, must be limited to the narrow concept, level, current-task connection, minimal evidence, language/reading presentation and practice classification; provider training must be disabled.
