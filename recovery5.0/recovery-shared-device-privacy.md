# Recovery Shared-Device Privacy

Private Session avoids inappropriate persistence. Device-only storage is user scoped, protected, expiring, non-syncing, and locally deletable. Selected logout cleanup clears cached content, decrypted offline keys, and notification tokens, prevents browser-back exposure, and protects the next account.

Downloads show a shared-device warning and use privacy-safe names. Offline packages exclude sensitive emotional, safety, integrity, diagnosis, accommodation, full message, and tutor-note data by default and revalidate without broadening shares.
