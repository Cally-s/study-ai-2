# Offline Accessibility and Language

Text-only and accessible packages preserve keyboard order, headings/landmarks/status, TTS-ready text, reviewed STT draft flow, high contrast/forced colours, Reduced Motion, 200%/~320px reflow, bilingual/RTL content, canonical glossary, transcripts, descriptions, print, and transcript-backed audio. Settings come from a data-minimized Step 63 projection and do not alter criteria. Missing optional media never blocks the task; missing essential alternatives block package publication.
