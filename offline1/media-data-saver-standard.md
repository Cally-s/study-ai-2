# Media Data-Saver Standard

Trusted server metadata must provide title/file/mime/bytes/version/hash/authorization, quality/duration and transcript/audio/offline alternatives before loading. Product-configured warning threshold defaults to 25 MB in the prototype.

Images need compressed responsive variants, dimensions and essential/decorative classification. Audio needs supported codecs/bitrates and smaller variants. Video never preloads/autoplays; transcript/captions/text remain available and audio-only must not remove essential diagrams/safety. Required movement needs a smaller controlled version/static frames/description plus intentional full load.

Download Later records a private queue item only. A production manager needs explicit start/pause/resume/cancel/retry/remove, progress/size/expiry/auth/storage states and Remove All. No automatic Wi-Fi assumptions or hidden downloads.
Step 17 previews show total/component estimates and trust status. Low Data/Text Only omit optional media; large trusted packages reuse existing warning/Download Later without preload/autoplay.
