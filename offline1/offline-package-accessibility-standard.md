# Offline Package Accessibility Standard

Implemented output is semantic printable HTML with language/direction, headings, DOM reading order, contents links, selectable/searchable/copyable text, preserved code whitespace, visible audio-equivalent text and no autoplay. Images require descriptions and tables/math/code must remain structured text. Accessible PDF generation/tags/forms and actual reader testing are unavailable; PDF requests are rejected. Keyboard, screen reader, zoom, RTL and print tests remain pending.
Step 18 review plans use the same semantic printable HTML alternative with language, direction, headings, contents order, selectable text and print-safe styling.
