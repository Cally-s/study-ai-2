# Text-First Lessons

Load page title, objective, current instruction, required canonical terms, explanation, student action, warnings, source/verification notices, and feedback/progress controls before optional compressed illustrations, audio, or media. Essential content remains usable if media never loads. Bilingual text, keyboard/screen-reader structure, privacy, policy, final-answer limits, warnings, sources, and identical assessment criteria remain intact. Low-Bandwidth AI responses request concise text structure, not lower evidence standards.
