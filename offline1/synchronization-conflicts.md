# Synchronization Conflicts

Conflicts include changed local/server progress, package/activity/policy/safeguard/consent/source/group/account/tenant state, closure, existing submission, corruption, and unavailable records. Silent last-write-wins is prohibited. Preserve both immutable references and a safe difference summary. Authorized choices are Keep Local, Keep Online, Combine, or Keep Both, with student confirmation and teacher review when policy/assessment requires it. Conflict, changed source, or expired package never deletes work or blames the student.
